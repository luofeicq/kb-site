必修第一册 · 第一章物质分类 · 离子反应 · 氧化还原

一、知识主线

1. 物质的分类：先看是不是一种物质，再看是不是一种元素

层级判断依据常见坑
混合物 / 纯净物有几种物质盐酸、氨水、漂白粉、水玻璃、福尔马林都是混合物；冰水混合物是纯净物
单质 / 化合物有几种元素O₂ 和 O₃ 混在一起仍是混合物；HD 是化合物（不同核素也算不同元素）
电解质 / 非电解质水溶液或熔融态能否导电只看化合物；单质既不是电解质也不是非电解质；CO₂、SO₂、NH₃ 本身不电离，是非电解质，但它们的水化物是电解质
强 / 弱电解质是否完全电离BaSO₄、CaCO₃ 难溶，但溶解的那部分完全电离，属强电解质

2. 分散系：按粒子直径分三档

分散系粒子直径特征实例
溶液< 1 nm均一、透明、稳定，能透过滤纸和半透膜NaCl 溶液
胶体1–100 nm均一、透明、介稳定，透过滤纸但不能透过半透膜，有丁达尔效应Fe(OH)₃ 胶体、豆浆、雾、烟
浊液> 100 nm不均一、不透明、不稳定泥水、油水

胶体的三个性质要能对上号：丁达尔效应（光通过时出现光路，用来区分胶体和溶液）、电泳（胶粒带电，在电场中定向移动）、聚沉（加电解质、加热、加带相反电荷的胶体）。

制备 Fe(OH)₃ 胶体 向沸水中滴加饱和 FeCl₃ 溶液，继续煮沸至液体呈红褐色，立即停止加热。写 FeCl₃ + 3H₂O --Δ--> Fe(OH)₃(胶体) + 3HCl。
不能写成沉淀符号，不能搅拌，不能用 NaOH 溶液——那是制沉淀，不是制胶体。

3. 离子反应：核心是"拆不拆"

离子方程式把溶液中真正参加反应的粒子写出来。判断拆不拆只有一个标准：这个物质在溶液里是不是主要以自由离子形式存在。

要拆成离子保留化学式
强酸（HCl、H₂SO₄、HNO₃、HBr、HI、HClO₄）
强碱（NaOH、KOH、Ba(OH)₂）
可溶性盐（含 Na⁺、K⁺、NH₄⁺、NO₃⁻ 的盐，以及大部分氯化物、硫酸盐）		弱酸（CH₃COOH、HClO、H₂CO₃、H₂S、HF）
弱碱（NH₃·H₂O、Fe(OH)₃、Cu(OH)₂）
难溶物（BaSO₄、AgCl、CaCO₃）
气体（CO₂、SO₂、NH₃）
氧化物（Na₂O、Fe₂O₃）
水

书写四步：写化学方程式 → 把可拆的拆成离子 → 删掉两边相同的离子 → 检查电荷守恒和质量守恒。

离子共存题的唯一思路 看这四个字就够：沉、气、弱、氧。能不能生成沉淀、气体、弱电解质（含水）、能不能发生氧化还原（Fe³⁺ 与 I⁻、MnO₄⁻ 与 Cl⁻、NO₃⁻ 酸性条件与 Fe²⁺），再加一条隐含的"无色溶液"排除有色离子（Cu²⁺ 蓝、Fe³⁺ 黄、Fe²⁺ 浅绿、MnO₄⁻ 紫红）。

4. 氧化还原反应：本质是电子转移，特征是化合价升降

概念定义常见物质
氧化剂得电子、化合价降低、被还原、发生还原反应，生成还原产物O₂、Cl₂、浓硫酸、HNO₃、KMnO₄、FeCl₃、H₂O₂
还原剂失电子、化合价升高、被氧化、发生氧化反应，生成氧化产物金属单质、H₂、C、CO、SO₂、KI、FeSO₄、Na₂SO₃

可操作
点下面的反应切换。上方是还原剂失电子的那条桥，下方是氧化剂得电子的那条桥，横跨的电子数一定相等——这就是配平和计算的全部依据。

三、易错辨析

容易混的一对关键区别
氧化性 vs 还原性氧化性是得电子的能力，还原性是失电子的能力。同一物质可能两者都有（如 SO₂ 既有氧化性又有还原性，但以还原性为主）
电解质 vs 导电电解质不一定导电（固体 NaCl 不导电）；导电的不一定是电解质（铜、盐水）
Cl₂ 的漂白 vs SO₂ 的漂白Cl₂ 靠 HClO 强氧化性，不可逆；SO₂ 是与有色物质化合生成不稳定无色物，可逆，加热复色
Fe³⁺ 与 Fe²⁺ 的检验Fe³⁺ 用 KSCN 变红（专属）；Fe²⁺ 用 K₃[Fe(CN)₆] 生成蓝色沉淀（专属），加 KSCN 无变化只能说明没有 Fe³⁺

四、例题精解

例　在反应 KClO₃ + 6HCl(浓) = KCl + 3Cl₂↑ + 3H₂O 中，被氧化的 HCl 与参加反应的 HCl 的物质的量之比是多少？转移电子数为多少？

第一步，标价态。KClO₃ 中 Cl 为 +5，HCl 中 Cl 为 −1，产物 Cl₂ 中 Cl 为 0。

第二步，找升降。+5 → 0，降 5，得 5e⁻，KClO₃ 是氧化剂。−1 → 0，升 1，失 1e⁻，HCl 是还原剂。

第三步，电子守恒定系数。得失要相等：1 个 ClO₃⁻ 得 5e⁻，需要 5 个 Cl⁻ 各失 1e⁻。所以生成 3 mol Cl₂ 里，1 mol Cl 来自 KClO₃，5 mol Cl 来自 HCl。另外 1 mol HCl 变成 KCl，化合价没变，没被氧化。

答案：被氧化的 HCl 是 5 mol，参加反应的是 6 mol，比值 5 : 6。转移电子 5 mol。

这题的坎在哪 看到 6HCl 就以为 6 个都被氧化，是这类题最常见的错。有一份 HCl 只提供酸性的 H⁺ 和 Cl⁻ 去配 KCl，它一个电子都没给。判断"被氧化的量"只能看化合价有没有变的那部分。

五、分层练习

基础

1. 下列物质中，属于强电解质的是（　）

A. 醋酸　B. 氨水　C. 硫酸钡　D. 二氧化碳

答案与解析

C

醋酸是弱酸，弱电解质。氨水是混合物，既不是电解质也不是非电解质。CO₂ 本身不电离，是非电解质。BaSO₄ 虽然难溶，但溶解的部分完全电离，是强电解质。

2. 写出下列反应的离子方程式：

(1) 碳酸钙与盐酸反应　(2) 氢氧化钡与稀硫酸反应　(3) 铁与稀盐酸反应

答案与解析

(1) CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑

(2) Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ = BaSO₄↓ + 2H₂O

(3) Fe + 2H⁺ = Fe²⁺ + H₂↑

(1) CaCO₃ 难溶，写化学式。(2) 两组离子都反应，一个都不能删。(3) 铁与非氧化性酸生成 Fe²⁺，不是 Fe³⁺。

提升

3. 已知氧化性 Cl₂ > Br₂ > Fe³⁺ > I₂。向 FeBr₂ 溶液中通入少量 Cl₂，最先被氧化的是哪种离子？写出反应的离子方程式。

答案与解析

最先被氧化的是 Fe²⁺：2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻

还原性顺序是 I⁻ > Fe²⁺ > Br⁻（与氧化性顺序相反）。FeBr₂ 溶液里只有 Fe²⁺ 和 Br⁻，还原性强的是 Fe²⁺，所以 Cl₂ 先氧化它。只有 Cl₂ 过量时才会氧化 Br⁻。

通入少量 Cl₂ 时若写成 Br⁻ 被氧化，就把顺序弄反了。

必修第一册 · 第二章钠、氯、铁及其化合物 · 物质的量

元素化合物是"素材库"，物质的量是"计算尺"。高考把两者绑在一起考：以 Na、Cl、Fe 为载体，算物质的量、浓度、产率。

一、知识主线

1. 钠及其化合物

物质关键性质反应
Na银白色软金属，密度小于水，熔点低；常温生成 Na₂O，点燃生成 Na₂O₂2Na + 2H₂O = 2NaOH + H₂↑（浮、熔、游、响、红）
Na₂O₂淡黄色固体，既是氧化剂又是还原剂（自身歧化）2Na₂O₂ + 2H₂O = 4NaOH + O₂↑
2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂
Na₂CO₃俗称纯碱、苏打，易溶于水，溶液显碱性Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑（速率为快）
NaHCO₃俗称小苏打，溶解度较小，受热易分解2NaHCO₃ --Δ--> Na₂CO₃ + H₂O + CO₂↑
Na₂O₂ 的两个常考结论 ① 与 H₂O、CO₂ 反应时，Na₂O₂ 中 −1 价氧一半升到 0、一半降到 −2，每生成 1 mol O₂ 转移 2 mol 电子。
② 固体增重规律：Na₂O₂ 吸收 CO₂ 相当于吸收 CO，吸收 H₂O 相当于吸收 H₂。所以 "Na₂O₂ + 有机物充分燃烧产物" 的增重，等于原有机物中 CO 和 H₂ 部分的质量。

2. 氯及其化合物

MnO₂ + 4HCl(浓) --Δ--> MnCl₂ + Cl₂↑ + 2H₂O　（实验室制法，需加热，稀盐酸不反应）
反应对象现象 / 产物
Na剧烈燃烧，黄色火焰，白烟（NaCl）
Fe点燃生成 FeCl₃（棕褐色烟），不是 FeCl₂
Cu生成 CuCl₂，棕黄色烟
H₂苍白色火焰，瓶口白雾
H₂OCl₂ + H₂O ⇌ HCl + HClO，氯水的成分是"三分子四离子"
NaOHCl₂ + 2NaOH = NaCl + NaClO + H₂O（尾气吸收）

氯水的成分：Cl₂、H₂O、HClO 三种分子；H⁺、Cl⁻、ClO⁻、OH⁻ 四种离子。所以氯水有酸性（H⁺）、漂白性（HClO）、氧化性（Cl₂、HClO）。

3. 铁及其化合物：一张"铁三角"

Fe --Cl₂/O₂(足)--> Fe³⁺ ；Fe³⁺ --Fe、Cu、I⁻、S²⁻--> Fe²⁺ ；Fe²⁺ --Cl₂、HNO₃、O₂--> Fe³⁺
物质颜色注意
FeO黑色碱性氧化物
Fe₂O₃红棕色俗称铁红，红色油漆颜料
Fe₃O₄黑色复杂氧化物，可看作 FeO·Fe₂O₃，有磁性
Fe(OH)₂白色极易被氧化：4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃，颜色白→灰绿→红褐
Fe(OH)₃红褐色胶体可净水
制备 Fe(OH)₂ 为什么必须"防氧" 三件事：① 用煮沸过的蒸馏水配溶液（去溶解氧）；② 加苯或植物油液封；③ 胶头滴管伸到液面以下再滴 NaOH。缺一个，看到的就直接是灰绿色。

4. 物质的量：把宏观质量和微观粒子连起来

n = m / M = N / NA = V / Vm = c · V液
量符号单位易错点
摩尔质量Mg/mol数值等于相对分子质量，但单位不能省
气体摩尔体积VmL/mol只对气体，标况（0 ℃、101 kPa）下 22.4 L/mol；常温常压不是 22.4
物质的量浓度cmol/LV 是溶液体积，不是溶剂体积

二、高频考点

  • 阿伏加德罗常数正误判断：常设在"标况下非气体"（水、SO₃、CCl₄、苯）、"溶液中离子数"（要考虑水解、弱电解质部分电离）、"可逆反应不能进行到底"（如 2NO₂ ⇌ N₂O₄）、"气体摩尔体积的适用条件"。
  • 配制一定物质的量浓度溶液：计算 → 称量 → 溶解（冷却）→ 转移（玻璃棒引流）→ 洗涤 2–3 次并转入 → 定容（离刻度线 1–2 cm 改胶头滴管）→ 摇匀。误差分析只看一个式子：c = n/V，n 偏小或 V 偏大，浓度就偏低。
  • Na₂CO₃ 与 NaHCO₃ 的鉴别与除杂：加热法、滴加盐酸的速率法、BaCl₂ 或 CaCl₂ 溶液法。除去 NaHCO₃ 中的 Na₂CO₃ 通 CO₂；除去 Na₂CO₃ 中的 NaHCO₃ 加热。

三、易错辨析

易混点辨析
Na₂O₂ 中的阴离子是 O₂²⁻（过氧根），不是两个 O²⁻。阴阳离子个数比 1 : 2
Cl₂ 与 Fe 反应无论 Cl₂ 少量还是过量，都生成 FeCl₃。铁与盐酸才生成 FeCl₂
干燥 Cl₂用浓硫酸，不能用碱石灰、不能用无水 CaCl₂ 之外的碱性干燥剂
Fe³⁺ 与 S²⁻不能共存，发生氧化还原：2Fe³⁺ + S²⁻ = 2Fe²⁺ + S↓
Vm = 22.4 L/mol只在标况下成立。标准状况指 0 ℃、101 kPa，不是 25 ℃
口 诀 钠的焰色黄、钾的焰色紫（要透过蓝色钴玻璃滤掉钠的黄光）。
Fe²⁺ 检验记"蓝"：铁氰化钾 K₃[Fe(CN)₆] 遇 Fe²⁺ 生成蓝色沉淀，这是 Fe²⁺ 的专属反应；Fe³⁺ 记"红"：KSCN 变血红。

四、例题精解

例　将 7.8 g Na₂O₂ 投入 100 g 水中，充分反应后，求：① 生成 O₂ 的物质的量；② 所得溶液中 NaOH 的质量分数；③ 转移电子数。

① M(Na₂O₂) = 78 g/mol，n = 7.8/78 = 0.1 mol。

2Na₂O₂ + 2H₂O = 4NaOH + O₂↑　　n(O₂) = 0.05 mol，标况 1.12 L

② n(NaOH) = 0.2 mol，m(NaOH) = 0.2 × 40 = 8 g。溶液质量 = 7.8 + 100 − 逸出的 O₂（0.05 × 32 = 1.6 g）= 106.2 g。

w(NaOH) = 8 / 106.2 × 100% ≈ 7.5%

③ Na₂O₂ 中 O 为 −1 价，生成 O₂ 时一半升到 0、一半降到 −2。每生成 1 mol O₂ 转移 2 mol e⁻，所以转移 0.1 mol。

三处必错 ① 溶液质量忘了减掉跑掉的氧气，直接用 107.8 g 算；② 电子数算成 0.05 mol（只算了失电子那一半）；③ 把 NaOH 的物质的量当成 0.1 mol。

五、分层练习

基础

1. 用 NA 表示阿伏加德罗常数的值，下列说法正确的是（　）

A. 标准状况下，22.4 L H₂O 含有的分子数为 NA

B. 1 mol Na₂O₂ 与足量水反应，转移电子数为 2NA

C. 1 L 0.1 mol/L 的 Na₂CO₃ 溶液中 CO₃²⁻ 数目为 0.1NA

D. 常温常压下，32 g O₂ 含有的氧原子数为 2NA

答案与解析

D

A 错：标况下水是液体，不能用 22.4 L/mol。B 错：1 mol Na₂O₂ 与水反应转移 1 mol 电子（歧化，只有一半氧被氧化）。C 错：CO₃²⁻ 会水解，数目小于 0.1NA。D 对：32 g O₂ 是 1 mol O₂，含 2 mol 氧原子，与温度压强无关。

2. 除去下列物质中的少量杂质（括号内为杂质），写出所用试剂和操作方法：

(1) Na₂CO₃ 固体（NaHCO₃）　(2) NaHCO₃ 溶液（Na₂CO₃）　(3) Cl₂（HCl）

答案与解析

(1) 加热至质量不再变化　(2) 通入足量 CO₂　(3) 通过饱和食盐水后干燥

(1) NaHCO₃ 受热分解转化为 Na₂CO₃。(2) Na₂CO₃ + CO₂ + H₂O = 2NaHCO₃。(3) HCl 极易溶于水被吸收，Cl₂ 在饱和食盐水中溶解度很小，损失最少。不能用 NaOH 溶液——那会把 Cl₂ 也吸收掉。

提升

3. 将 5.6 g 铁粉加入 100 mL 2 mol/L 的 FeCl₃ 溶液中，充分反应后，求溶液中 Fe²⁺ 的物质的量浓度（体积变化忽略）。

答案与解析

c(Fe²⁺) = 3 mol/L

n(Fe) = 5.6/56 = 0.1 mol，n(FeCl₃) = 2 mol/L × 0.1 L = 0.2 mol。

先判过量：反应 Fe + 2Fe³⁺ = 3Fe²⁺，0.1 mol Fe 恰好消耗 0.2 mol Fe³⁺。两者恰好完全反应，无剩余。

再用铁元素守恒：反应前铁元素总量 = 0.1 mol（Fe 单质）+ 0.2 mol（FeCl₃ 中）= 0.3 mol。反应后全部以 Fe²⁺ 形式存在，故 n(Fe²⁺) = 0.3 mol。

c(Fe²⁺) = 0.3 mol ÷ 0.1 L = 3 mol/L。

用元素守恒一步算完，比"原有多少、生成多少、加起来"稳得多。凡是同一元素在不同物质间转化，优先想守恒。

二、高频考点

  • "位—构—性"推断：给短周期元素的性质或结构片段，推元素，再判断选项。突破口通常是：最外层电子数是次外层 2 倍（C）、3 倍（O）、电子总数是最外层 3 倍（Be 或 Ar 之类）、地壳中含量最高的两种元素（O、Si）。
  • 化学键判断：判断某物质含哪种键、是离子化合物还是共价化合物。常考 Na₂O₂、NaOH、NH₄Cl、AlCl₃。
  • 电子式书写：离子化合物要标电荷和方括号，共价化合物不标。
  • "10 电子/18 电子微粒"：10 电子有 Ne、HF、H₂O、NH₃、CH₄、Na⁺、Mg²⁺、Al³⁺、NH₄⁺、H₃O⁺、OH⁻、F⁻、O²⁻、N³⁻。

四、例题精解

例　短周期元素 X、Y、Z、W 的原子序数依次增大。X 原子的最外层电子数是其内层电子数的 3 倍；Y 是地壳中含量最多的金属元素；Z 与 X 同主族；W 的简单阴离子与 Ar 原子的电子层结构相同。回答：

(1) 写出四种元素的符号；(2) Z 在周期表中的位置；(3) 比较 Y³⁺、Z²⁻、W⁻ 的半径大小；(4) 比较 Z、W 最高价氧化物对应水化物的酸性。

X："最外层是内层的 3 倍"。短周期元素内层最多 2 个（第二周期）或 10 个（第三周期）。若内层 2 个，最外层 6 个，为 O；若内层 10 个，最外层需 30 个，不存在。X = O。

Y：地壳元素含量排序是 O > Si > Al > Fe。含量最多的金属是 Al。且 13 > 8，符合"原子序数依次增大"。Y = Al。

Z：与 X（O）同主族，即第ⅥA 族，原子序数大于 13，只能是第三周期的 S。Z = S。

W：简单阴离子与 Ar 电子层结构相同，即得电子后有 18 个电子，W 为 17 号氯。W = Cl。

检验原子序数：8 < 13 < 16 < 17，依次增大，条件全部吻合。

(1) O、Al、S、Cl

(2) 第三周期第ⅥA 族

(3) Al³⁺ 只有 2 个电子层（10 电子），S²⁻ 与 Cl⁻ 都是 3 个电子层（18 电子），电子层多的半径大；同为 18 电子的 S²⁻ 与 Cl⁻，核电荷数大的半径小。故 S²⁻ > Cl⁻ > Al³⁺。

(4) 最高价含氧酸分别是 H₂SO₄ 和 HClO₄。同周期从左到右非金属性增强，最高价含氧酸酸性增强，故 HClO₄ > H₂SO₄（高氯酸是中学阶段最强的含氧酸）。

这类题的通用打法 先把每个条件单独翻译成"元素候选集"，再取交集，最后用"原子序数依次增大"这个排序条件筛。最忌讳边推边猜——推出一个就往下走，走到后面发现矛盾再回头，时间全耗掉。
另外记牢一句：比较微粒半径先看电子层数，层数相同再看核电荷数，核电荷数越大半径越小。

五、分层练习

基础

1. 下列物质中，既含离子键又含非极性共价键的是（　）

A. NaOH　B. Na₂O₂　C. HCl　D. NH₄Cl

答案与解析

B

Na₂O₂ 中 Na⁺ 与 O₂²⁻ 之间是离子键，O₂²⁻ 内部两个氧原子之间是非极性共价键。A 中 O—H 是极性共价键；C 只有极性共价键；D 中 N—H 是极性共价键。

2. 比较下列各组微粒的半径大小：

(1) Na、Mg、Al　(2) O²⁻、F⁻、Na⁺、Mg²⁺　(3) F、Cl、Br

答案与解析

(1) Na > Mg > Al　(2) O²⁻ > F⁻ > Na⁺ > Mg²⁺　(3) Br > Cl > F

(1) 同周期从左到右半径减小。(2) 电子层结构相同的微粒，核电荷数越大半径越小。(3) 同主族从上到下半径增大。

提升

3. 已知 X、Y、Z 三种短周期元素的原子序数依次增大，X 与 Z 同主族，Y 的原子半径在同周期中最大，Z 的最外层电子数是 Y 的最外层电子数的 3 倍。判断三种元素并说明理由。

答案与解析

X = B，Y = Na，Z = Al

第一步，用"半径最大"锁定 Y。同一周期中原子半径最大的元素是该周期第一个元素，即第ⅠA 族。短周期里只有 Li 和 Na 两个候选。

第二步，用"3 倍"锁定 Z 的族。Z 的最外层电子数是 Y 的 3 倍。Y 最外层只有 1 个电子，故 Z 最外层 3 个电子，属第ⅢA 族。

第三步，用"原子序数依次增大"剔除错误组合。若 Y = Li(3)，Z 应为第二周期ⅢA 的 B(5)，但 X 与 Z 同主族且原子序数小于 Y，不可能有比 B 更轻的ⅢA 元素，排除。若 Y = Na(11)，Z = Al(13)，X 与 Z 同主族且序数小于 11，只能是 B(5)。

检验：B(5) < Na(11) < Al(13) 依次增大；B 与 Al 同属第ⅢA 族；Na 在第三周期半径最大；Al 最外层 3 个电子恰为 Na 的 3 倍。全部成立。

元素化合物里最容易出推断题和工业流程题的板块。核心是"价态—物质—性质"三条线：同种元素不同价态怎么转化。

一、知识主线

1. 硫：一张价态图

H₂S(−2) → S(0) → SO₂(+4) → SO₃(+6) → H₂SO₄(+6)
物质关键性质高考常见考法
SO₂酸性氧化物、还原性为主、漂白性（可逆）使品红褪色但加热复色；使酸性 KMnO₄ 褪色（还原性，不是漂白）

物质要点

电子守恒：n(金属) × 化合价变化 = n(NO₂) + 3n(NO)
氮守恒：n(HNO₃) = 2n(M(NO₃)ₓ) + n(NO₂) + n(NO)

二、高频考点

  • SO₂ 与 CO₂ 的鉴别与除杂：用品红或酸性 KMnO₄ 检验 SO₂，再用溴水或酸性 KMnO₄ 除去；除去 CO₂ 中的 SO₂ 用饱和 NaHCO₃ 溶液。
  • 氮氧化物溶于水的计算：4NO₂ + O₂ + 2H₂O = 4HNO₃；4NO + 3O₂ + 2H₂O = 4HNO₃。可合并成一个总反应，按"谁过量谁剩余"分析。
  • 喷泉实验的成立条件：气体极易溶于液体或与液体迅速反应，造成压强差。NH₃ 与 H₂O、HCl 与 H₂O、SO₂ 与 NaOH、CO₂ 与 NaOH 都能做。

易混点辨析
浓硫酸的吸水性与脱水性吸水性是吸收现成的水分子（干燥气体）；脱水性是按 H:O = 2:1 夺走有机物中的氢和氧（蔗糖变黑）

四、例题精解

例　将 1.92 g 铜粉与 50 mL 一定浓度的硝酸反应，铜完全溶解，收集到标准状况下 1.12 L 气体。求：① 转移的电子数；② 消耗的硝酸的物质的量。

① 电子守恒。n(Cu) = 1.92/64 = 0.03 mol，Cu 从 0 到 +2，每个铜失 2 个电子，共失 0.06 mol e⁻。转移电子 0.06 mol。

② 气体成分。n(气体) = 1.12/22.4 = 0.05 mol。设 NO₂ 为 x mol，NO 为 y mol：

x + y = 0.05　　x + 3y = 0.06

解得 y = 0.005 mol，x = 0.045 mol。

③ 氮守恒。硝酸的去向有两处：生成 Cu(NO₃)₂，和变成气体。n(Cu(NO₃)₂) = 0.03 mol，含 NO₃⁻ 0.06 mol。气体中的氮 0.05 mol。

n(HNO₃) = 0.06 + 0.05 = 0.11 mol

答案：转移电子 0.06 mol，消耗硝酸 0.11 mol。

不要急着分类讨论歧化 这题不需要先判断气体到底是 NO₂ 还是 NO 占多少——电子守恒一次就锁定了总电子数，再用总气体量解二元一次方程组。凡是"硝酸与金属、气体成分不明"的题，都走"电子守恒 + 原子守恒"这条路，比逐段分类快。

B. SO₂ 使品红溶液褪色，加热后恢复红色，说明该漂白是可逆的

(1) 铜与浓硫酸共热　(2) 铜与稀硝酸反应　(3) 二氧化氮与水反应

(1) Cu + 2H₂SO₄(浓) --Δ--> CuSO₄ + SO₂↑ + 2H₂O

(2) 3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

(3) 3NO₂ + H₂O = 2HNO₃ + NO

(1) 浓硫酸表现氧化性和酸性，硫被还原到 +4。(2) 稀硝酸被还原到 +2，配平后系数 3、8、3、2、4。(3) 这是 NO₂ 的歧化，氮从 +4 一部分升到 +5、一部分降到 +2。

提升

3. 将盛有 20 mL NO 和 NO₂ 混合气体的量筒倒立于水槽中，充分反应后剩余 12 mL 气体。求原混合气体中 NO 和 NO₂ 的体积比（气体体积在同温同压下测定）。

答案与解析

V(NO) : V(NO₂) = 2 : 1

3NO₂ + H₂O = 2HNO₃ + NO，每 3 体积 NO₂ 反应后只剩 1 体积 NO，体积减少 2 体积。

必修第二册 · 第六章 / 选择性必修1 第一章化学反应与能量

选择题一题（热化学方程式正误、盖斯定律计算），大题中常与平衡、工艺条件合并出现。

一、知识主线

1. 放热与吸热的本质

断键要吸收能量，成键会放出能量。一个反应是放热还是吸热，取决于断键吸收的总能量与成键放出的总能量哪个大。放热反应中，生成物的总能量低于反应物的总能量。

ΔH = Σ(反应物键能) − Σ(生成物键能)　　ΔH < 0 放热，ΔH > 0 吸热
常见的放热/吸热反应，记住"例外"就够了 大多数化合、燃烧、中和、金属与酸的反应都是放热；大多数分解反应吸热。
例外必记：C 与 CO₂ 生成 CO、Ba(OH)₂·8H₂O 与 NH₄Cl 的反应、大多数以 C、H₂、CO 作还原剂的还原反应，都是吸热。而 Al 与 Fe₂O₃ 的铝热反应、Na 与水的反应是放热。

必须标 ΔH 的符号和单位单位是 kJ/mol，写在方程式右侧，用分号隔开
系数可以是分数系数表示物质的量，不表示分子个数
系数翻倍，ΔH 同步翻倍方程式的 ΔH 与系数绑定，不能只改一边
正逆反应的 ΔH 等值反号ΔH(正) = −ΔH(逆)

3. 燃烧热与中和热

项目燃烧热中和热
定义1 mol 纯物质完全燃烧生成稳定氧化物时放出的热量稀溶液中强酸与强碱反应生成 1 mol 水时放出的热量
关键限定可燃物为 1 mol；产物必须是最稳定氧化物（C→CO₂，H→H₂O(l)）生成 1 mol H₂O；稀溶液；强酸强碱
数值因物质而异约 57.3 kJ/mol，是一个定值

4. 盖斯定律

反应热只与始态和终态有关，与路径无关。所以可以把已知方程式像代数式一样加减乘除，凑出目标方程式，ΔH 同步运算。

操作三步 ① 找出目标方程式中各物质在哪个已知方程式中出现；② 确定每个已知方程式的系数和方向（正向、逆向、乘几）；③ 对 ΔH 做同样的运算。
技巧：先盯住只在一个方程式中出现的物质，它决定那个方程式要不要乘系数。

二、高频考点

  • 热化学方程式正误判断：查状态、查符号、查单位、查系数与 ΔH 是否匹配。
  • 键能估算 ΔH：注意只算参与反应的键，不要把所有键都算进去。
  • 盖斯定律计算：常见于"由已知反应求未知反应 ΔH"，也可以用"总能量变化 = 各步之和"。
  • 图像题：给出能量-反应进程图，判断 ΔH 正负、催化剂是否改变 ΔH（不改变）。

三、易错辨析

易混点辨析
ΔH 与反应条件热化学方程式中的 ΔH 与是否加热无关。加热只是活化能的问题
催化剂对 ΔH 的影响只降低活化能，不改变始态终态能量差，ΔH 不变
燃烧热 vs 反应热燃烧热是特定条件下的反应热（1 mol 可燃物、完全燃烧、稳定产物）；反应热是一般概念
中和热测定值偏小因为量热计有热量散失，以及使用了保温不良的装置；不能因此改数据，只能说"约"
口 诀 断键吸、成键放；放热 ΔH 负、吸热 ΔH 正。
燃烧热记四个"最"：1 mol、完全燃烧、稳定氧化物、25 ℃ 101 kPa。

四、例题精解

例　已知：
① C(s) + O₂(g) = CO₂(g)　ΔH₁ = −393.5 kJ/mol
② 2CO(g) + O₂(g) = 2CO₂(g)　ΔH₂ = −566.0 kJ/mol
求 C(s) + ½O₂(g) = CO(g) 的 ΔH。

找目标：C(s) + ½O₂(g) → CO(g)。

看 C 出现在哪：只在①中，且系数为 1，直接用①。

看 CO 出现在哪：只在②中，但②的 CO 是反应物，系数 2。目标里 CO 是生成物，系数 1，所以②要逆向并除以 2：

CO₂(g) = CO(g) + ½O₂(g)　ΔH = +566.0/2 = +283.0 kJ/mol

相加：① + (−½ × ②)：

ΔH = −393.5 + 283.0 = −110.5 kJ/mol

答案：ΔH = −110.5 kJ/mol（放热）。

验算：C 完全燃烧放 393.5，CO 燃烧时每 1 mol 再放 283.0，两者相加 393.5 − 283.0 = 110.5，与答案一致。

A. 需要加热才能进行的反应一定是吸热反应

B. 放热反应在任何条件下都能自发进行

C. 化学反应中的能量变化主要形式是热量变化

提升

2. 已知：N₂(g) + 3H₂(g) ⇌ 2NH₃(g)　ΔH = −92.4 kJ/mol。若 1 mol N₂ 与 3 mol H₂ 在密闭容器中充分反应，实际放出的热量是多少？为什么？

答案与解析

小于 92.4 kJ

选择性必修1 · 第二章化学反应速率与化学平衡

这是整个反应原理的重心。选择题必考图像分析，大题必考平衡计算与条件选择。

一、知识主线

1. 反应速率

v = Δc / Δt　　（单位 mol/(L·s) 或 mol/(L·min)）

用不同物质表示速率时，速率之比等于化学计量数之比。比较速率大小时，必须先换算成同一种物质再比。

影响速率的因素：浓度（增大反应物浓度加快）、压强（对有气体参加且气体分子数变化的反应有效）、温度（升高加快，且正逆都加快）、催化剂、固体表面积。

有效碰撞理论，用它解释一切速率问题 分子要发生反应，必须①碰撞、②能量足够（达到活化能）、③取向合适。能发生反应的碰撞叫有效碰撞。
升温 → 活化分子百分数增加 → 有效碰撞增多 → 速率加快；
加催化剂 → 降低活化能 → 活化分子百分数增加 → 速率加快；
增大浓度 → 单位体积内活化分子数增加（百分数不变） → 速率加快。

2. 化学平衡状态

可逆反应进行到正反应速率等于逆反应速率、各物质浓度不再变化的状态。注意：平衡时反应没有停止，是动态平衡；各物质浓度不变但不一定相等。

能判断达到平衡不能判断（永远成立或与平衡无关）
v正 = v逆（同一物质，方向相反）各物质浓度相等
各组分浓度、质量分数、体积分数不再变化反应物转化率相等
恒容下总压不再变化（Δn ≠ 0 时）总质量、总体积不变
恒容下密度不再变化（有固体参与时）平均摩尔质量不变（Δn = 0 且全为气体时）
绝热容器中温度不再变化速率之比等于计量数之比

3. 平衡常数

对于 aA + bB ⇌ cC + dD　　K = c(C)c·c(D)d / [c(A)a·c(B)b]

K 只与温度有关，与浓度、压强、催化剂无关（固体和纯液体不写进表达式）。K 越大，反应进行得越完全。

图 6-1　勒夏特列原理：换个条件，平衡往哪走

可操作
以合成氨 N₂ + 3H₂ ⇌ 2NH₃（ΔH < 0）为例。拖温度、拖压强，或者点"加反应物/移走产物/加催化剂"，左边看转化率和 K 怎么变，右边看速率怎么从"正≠逆"回到"正=逆"。

4. 勒夏特列原理

改变影响平衡的一个条件，平衡会向减弱这种改变的方向移动。注意是"减弱"不是"消除"。

条件改变平衡移动方向对 K 的影响
增大反应物浓度正向移动K 不变
升高温度向吸热方向移动吸热反应 K 增大，放热反应 K 减小
增大压强向气体分子数减少的方向移动K 不变
加入催化剂不移动K 不变
恒容下充入惰性气体不移动K 不变

二、高频考点

  • 速率-时间图像：看清"突变"还是"渐变"。浓度改变导致一个速率突变，温度或压强改变导致两个速率同时突变但幅度不同，催化剂导致两者同等幅度突变。
  • 转化率-温度-压强图像：先看等温线（横坐标固定一条竖线），判断吸放热；再看等压线，判断 Δn 符号。
  • 平衡计算：列"三段式"（起始、变化、平衡），用转化率或 K 建立方程。
  • 工业条件选择：合成氨选 400–500 ℃、10–30 MPa、铁触媒，要同时权衡速率、平衡转化率和催化剂活性。

三、易错辨析

易混点辨析
v正 = v逆 与 v正 : v逆 = 计量数比前者才是平衡；后者只在特定时刻偶然成立，不能作判据
平衡常数与转化率K 只随温度变；转化率还受浓度、压强影响。所以"K 大"不代表"当前转化率大"
加压与充惰性气体恒容充惰性气体，各组分浓度不变，平衡不移动；恒压充惰性气体，相当于减压，平衡向气体分子数增多的方向移动
催化剂与转化率催化剂只缩短达到平衡的时间，不提高转化率
口 诀 平衡移动：升温向吸热，加压向气少。
看懂图像：先定一轴看一线，再看陡缓判速率——先固定温度看压强线，或固定压强看温度线，不要两轴一起看。

四、例题精解

例　在 2 L 密闭容器中充入 2 mol SO₂ 和 1 mol O₂，一定温度下发生 2SO₂(g) + O₂(g) ⇌ 2SO₃(g)。达到平衡时测得 SO₃ 为 1.6 mol。求：① SO₂ 的转化率；② 该温度下的平衡常数 K。

三段式（单位 mol，容器体积 2 L）：

2SO₂O₂2SO₃
起始210
变化−1.6−0.8+1.6
平衡0.40.21.6

① 转化率：α(SO₂) = 1.6/2 × 100% = 80%。

② 换算浓度：c(SO₂) = 0.2 mol/L，c(O₂) = 0.1 mol/L，c(SO₃) = 0.8 mol/L。

K = c²(SO₃) / [c²(SO₂)·c(O₂)] = 0.8² / (0.2² × 0.1) = 0.64 / 0.004 = 160

答案：转化率 80%，K = 160（注意 K 的单位取决于具体表达式，中学阶段一般只写数值）。

两处高频失分 ① 用物质的量直接代入 K，忘了除以体积；② 忘记先把系数平方。三段式写完，一定要单独检查"浓度换算"和"幂次"这两步。

基础

1. 对于反应 N₂(g) + 3H₂(g) ⇌ 2NH₃(g) ΔH < 0，下列措施既能加快反应速率又能提高 NH₃ 产率的是（　）

A. 升高温度　B. 增大压强　C. 使用催化剂　D. 及时分离出 NH₃

A 升温加快速率，但平衡逆向移动，产率降低。C 只加快速率，不改变产率。D 提高产率但减慢正反应速率（浓度降低）。B 加压同时使速率加快、平衡向气体分子数减少的方向（即生成 NH₃）移动。

2. 某温度下，反应 CO(g) + H₂O(g) ⇌ CO₂(g) + H₂(g) 的 K = 1.0。起始时 CO 和 H₂O 的浓度均为 1.0 mol/L，求平衡时 CO 的转化率。

答案与解析

50%

选择性必修1 · 第三章水溶液中的离子平衡

选择题必考（离子浓度大小比较、pH 计算），大题里常与滴定曲线、沉淀转化一起考。这一章是"定量"的分水岭。

一、知识主线

1. 弱电解质的电离平衡

CH₃COOH ⇌ CH₃COO⁻ + H⁺　　Ka = c(CH₃COO⁻)·c(H⁺) / c(CH₃COOH)

Ka 越大，酸性越强。电离度 α = 已电离的分子数 / 原有分子总数。稀释时电离度增大，但 c(H⁺) 减小（越稀越电离，但浓度还是被稀释掉了）。

一元强酸与一元弱酸的比较（浓度相同） c(H⁺)：强酸 > 弱酸；pH：强酸 < 弱酸；中和同量碱所需体积：相同；稀释 10 倍后 pH 变化：强酸变 1，弱酸变化小于 1。
反过来，pH 相同时：c(弱酸) > c(强酸)，中和能力弱酸更强。

2. 水的电离与 pH

H₂O ⇌ H⁺ + OH⁻　　Kw = c(H⁺)·c(OH⁻) = 1.0×10⁻¹⁴（25 ℃）

Kw 只随温度变化，升温增大。所以100 ℃ 时 pH = 6 仍是中性。

溶液类型pH 计算思路
强酸直接由 c(H⁺) 求 −lg
强碱先求 c(OH⁻)，再用 Kw 换算 c(H⁺)
弱酸/弱碱用 Ka 或 Kb 近似：c(H⁺) ≈ √(Ka·c)
酸碱混合先判断谁过量，按过量一方算；恰好中和则看盐的水解

3. 盐类水解

盐电离出的离子与水电离出的 H⁺ 或 OH⁻ 结合生成弱电解质，促使水的电离平衡正向移动。规律一句话：谁弱谁水解，谁强显谁性。

盐的类型水解情况溶液酸碱性实例
强酸强碱盐不水解中性NaCl、KNO₃
强酸弱碱盐阳离子水解酸性NH₄Cl、FeCl₃
强碱弱酸盐阴离子水解碱性CH₃COONa、Na₂CO₃
弱酸弱碱盐双水解看相对强弱CH₃COONH₄（中性）
水解的四个应用，考试常从这里出 ① 配制 FeCl₃ 溶液时加少量盐酸抑制水解；② 泡沫灭火器（Al³⁺ 与 HCO₃⁻ 双水解产生 CO₂）；③ 明矾净水（Al³⁺ 水解生成 Al(OH)₃ 胶体吸附杂质）；④ 加热蒸干某些盐溶液得不到原盐（如 AlCl₃ 蒸干得 Al₂O₃）。

4. 沉淀溶解平衡

AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq)　　Ksp = c(Ag⁺)·c(Cl⁻)

Ksp 只与温度有关。Q > Ksp 生成沉淀，Q = Ksp 饱和，Q < Ksp 不沉淀。沉淀转化的方向：由 Ksp 大的转化为 Ksp 小的（如 AgCl → AgI → Ag₂S）。

5. 酸碱中和滴定

图 7-1　滴定曲线：为什么指示剂不能随便选

可操作
拖滴定体积看 pH 怎么走。注意两条曲线的"突跃"位置差得很远：强酸强碱在 pH 4–10 之间几乎垂直，弱酸用强碱滴定则突跃缩到 7–9 附近。指示剂的变色范围必须落在突跃之内，否则误差无法控制。

二、高频考点

  • 离子浓度大小比较：单一溶液中抓"水解程度小"，混合溶液中抓"电荷守恒 + 物料守恒 + 质子守恒"。
  • 三个守恒式：电荷守恒（正电荷总数 = 负电荷总数）、物料守恒（某元素总量不变）、质子守恒（得失 H⁺ 相等）。
  • 滴定误差分析：只看一个式子 c(待测) = c(标准)·V(标准)/V(待测)，判断 V(标准) 偏大还是偏小。
  • 沉淀转化与 Ksp 计算：常用于工艺流程题，判断某离子是否沉淀完全（一般以浓度小于 1×10⁻⁵ mol/L 为完全）。

三、易错辨析

易混点辨析
pH = 7 一定是中性？只在 25 ℃ 成立。温度升高 Kw 增大，中性时 pH < 7
水解程度与浓度盐溶液越稀，水解程度越大，但水解产生的离子浓度反而可能减小
Ksp 小的先沉淀？不同类型（如 AgCl 与 Ag₂CrO₄）不能只比 Ksp 大小，要用 Q 计算，或换算成溶解度
滴定终点与中和点中和点是恰好完全反应（强酸强碱 pH = 7），终点是指示剂变色点，两者不一定重合
口 诀 水解：有弱才水解，无弱不水解；越弱越水解，都弱双水解；谁强显谁性，同强显中性。
三种守恒：电荷看离子、物料看元素、质子看得失。

四、例题精解

例　常温下，将 0.1 mol/L 的 CH₃COOH 溶液与 0.1 mol/L 的 NaOH 溶液等体积混合，所得溶液中各离子浓度由大到小的顺序是什么？

第一步，判断反应。等体积等浓度，恰好完全反应，生成 CH₃COONa，浓度约 0.05 mol/L。

第二步，判断水解。CH₃COO⁻ 是弱酸根，水解：CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻，溶液显碱性，故 c(Na⁺) > c(CH₃COO⁻)，c(OH⁻) > c(H⁺)。

第三步，排序。水解程度很小，所以 c(CH₃COO⁻) 仍远大于 c(OH⁻)。

c(Na⁺) > c(CH₃COO⁻) > c(OH⁻) > c(H⁺)

验证用电荷守恒：c(Na⁺) + c(H⁺) = c(CH₃COO⁻) + c(OH⁻)。上面这个顺序代入是自洽的。

排序题的三步固定动作 ① 先确定溶质是什么、有没有过量；② 判断主要平衡（电离还是水解）；③ 用"电离/水解程度小"这个前提拉开数量级，最后用电荷守恒验证。三步做完再看选项，不要一上来就套守恒式。

基础

pH = 3 的盐酸 c(H⁺) = 1×10⁻³ mol/L；pH = 11 的 NaOH 中 c(OH⁻) = 1×10⁻³ mol/L。两者等体积混合，H⁺ 与 OH⁻ 恰好完全中和，剩余溶液为 NaCl 溶液，pH = 7。

提升

3. 已知 Ksp(AgCl) = 1.8×10⁻¹⁰，Ksp(AgI) = 8.5×10⁻¹⁷。向含 Cl⁻ 和 I⁻ 浓度均为 0.01 mol/L 的溶液中逐滴加入 AgNO₃ 溶液，哪种离子先沉淀？当 Cl⁻ 开始沉淀时，溶液中 I⁻ 的浓度是多少？

答案与解析

I⁻ 先沉淀；c(I⁻) ≈ 4.7×10⁻⁹ mol/L

先沉淀判断：开始沉淀所需 c(Ag⁺)：
对 Cl⁻：c(Ag⁺) = 1.8×10⁻¹⁰ / 0.01 = 1.8×10⁻⁸ mol/L
对 I⁻：c(Ag⁺) = 8.5×10⁻¹⁷ / 0.01 = 8.5×10⁻¹⁵ mol/L
所需 Ag⁺ 浓度小的先沉淀，所以 I⁻ 先沉淀。

第二步：当 c(Ag⁺) 达到 1.8×10⁻⁸ mol/L 时 Cl⁻ 开始沉淀，此时 I⁻ 仍在溶液中，满足 Ksp(AgI)：

c(I⁻) = 8.5×10⁻¹⁷ / 1.8×10⁻⁸ ≈ 4.7×10⁻⁹ mol/L

此时 I⁻ 已远小于 1×10⁻⁵ mol/L，说明 I⁻ 已沉淀完全。这也是"分步沉淀"分离离子的原理。

1. 原电池

2. 电解池

把电能转化为化学能。与电源负极相连的是阴极（发生还原），与正极相连的是阳极（发生氧化）。

电极放电顺序（阳离子得电子）
阴极Ag⁺ > Fe³⁺ > Cu²⁺ > H⁺ > Pb²⁺ > Fe²⁺ > Zn²⁺ > (H⁺) > Al³⁺ > Mg²⁺ > Na⁺
阳极（惰性）S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根
阳极（活泼金属）电极本身先溶解（如 Cu、Ag 作阳极）
四个电解应用，考法固定 氯碱工业：电解饱和食盐水，阳极 Cl₂、阴极 H₂、溶液中得 NaOH。
电镀：镀层金属作阳极，待镀件作阴极，电镀液含镀层金属离子（浓度基本不变）。
电解精炼铜：粗铜作阳极，纯铜作阴极，CuSO₄ 溶液作电解液（阳极泥中含 Au、Ag）。
电解熔融盐：制 Na、Mg、Al，注意 Al 是电解熔融 Al₂O₃（加冰晶石），不能电解 AlCl₃（共价化合物，熔融不导电）。

3. 金属的腐蚀与防护

类型条件实例
化学腐蚀金属与接触到的物质直接反应铁在高温下与 O₂ 反应
电化学腐蚀（析氢）酸性环境，正极放出 H₂铁在酸性溶液中
电化学腐蚀（吸氧）中性或弱酸性环境，正极消耗 O₂钢铁在潮湿空气中（最常见）

防护方法：覆盖保护层、改变金属内部结构（制成不锈钢）、电化学保护（牺牲阳极的阴极保护法：接更活泼的金属如 Zn；外加电流的阴极保护法：接电源负极）。

二、高频考点

  • 电极判断与电极反应式书写：先判正负极（或阴阳极），再写半反应，最后检查电子守恒与电荷守恒。
  • 电解计算：串联电路中各电极通过的电子数相等，按 n(e⁻) = It/F 或按电极反应式的计量关系换算。
  • 离子交换膜电解池：判断哪种离子通过哪种膜（阳离子交换膜只允许阳离子通过），是近年新高考的热点。
  • 可充电电池：放电时是原电池，充电时是电解池，注意"负极"在充电时变"阴极"。

三、易错辨析

易混点辨析
电子能否通过溶液不能。电子只在导线中移动，溶液中靠离子定向移动导电

电解池阳极一定溶解？只有活泼金属作阳极才溶解；惰性电极（Pt、石墨）上是溶液中的离子放电

电子流向记一条线：负极 → 导线 → 正极，电解池里是阳极 → 电源正极，方向永远一致。

四、例题精解

例　以石墨为电极，电解 500 mL 含 0.2 mol CuSO₄ 的溶液。当电路中通过 0.2 mol 电子时，阴极析出铜的质量是多少？溶液的 pH 如何变化？

阴极反应：Cu²⁺ + 2e⁻ = Cu。通过 0.2 mol 电子，生成 Cu 0.1 mol，质量 = 0.1 × 64 = 6.4 g。

阳极反应：4OH⁻ − 4e⁻ = O₂↑ + 2H₂O（或写成 2H₂O − 4e⁻ = O₂↑ + 4H⁺）。通过 0.2 mol 电子，生成 H⁺ 0.2 mol。

pH 变化：溶液中 H⁺ 增加 0.2 mol，相当于生成了 0.1 mol H₂SO₄，pH 减小（酸性增强）。

c(H⁺) = 0.2/0.5 = 0.4 mol/L，pH ≈ 0.4。

顺序问题别忽略 如果 CuSO₄ 只有 0.05 mol（即 Cu²⁺ 不够），那么电子先用于析铜，Cu²⁺ 耗尽后转为电解水（阴极放 H₂）。这题给的是 0.2 mol CuSO₄，足够消耗 0.4 mol 电子，所以只析铜。凡"通过多少电子"的题，先算电解质的量够不够。

4. 分子间作用力

  • 范德华力：普遍存在，随相对分子质量增大而增强（所以卤素单质熔沸点 F₂ < Cl₂ < Br₂ < I₂）。

四、例题精解

例　判断下列分子的中心原子杂化方式和空间构型：① H₂O　② NH₃　③ CO₂　④ SO₂

H₂O：O 有 6 个价电子，与 2 个 H 形成 2 个 σ 键，孤电子对 = (6 − 2×1)/2 = 2。价层电子对 = 2 + 2 = 4，sp³ 杂化，VSEPR 母体是四面体，去掉 2 个孤对后为 V 形，键角约 104.5°（小于 109°28′，因为孤对排斥更强）。

NH₃：N 有 5 个价电子，与 3 个 H 成键，孤电子对 = (5 − 3)/2 = 1。价层电子对 = 4，sp³ 杂化，三角锥形，键角约 107°。

CO₂：C 与 2 个 O 形成 2 个 σ 键，无孤对。价层电子对 = 2，sp 杂化，直线形，180°。

SO₂：S 有 6 个价电子，与 2 个 O 成 σ 键，孤电子对 = (6 − 2×2)/2 = 1。价层电子对 = 3，sp² 杂化，母体平面三角形，去掉 1 个孤对后为 V 形，键角约 119°。

SO₂ 为什么和 CO₂ 不一样 两者都是"中心原子连两个氧"，但 S 上还有 1 对孤电子，C 上没有。孤电子对既改变杂化方式（sp² 而不是 sp），也把分子从直线压成 V 形。做这类题一定要把孤电子对算出来，不能只看"几个原子"。

2. 比较下列各组物质的熔沸点高低并说明理由：

答案与解析

(3) 都是分子晶体，H₂O 分子间存在氢键，H₂S 没有，所以水的沸点异常高（虽然 H₂S 相对分子质量更大）。这是"氢键打破分子量规律"的经典例子。

  • 官能团的性质对应：给一个陌生有机物，问能发生哪些反应、消耗多少 mol 试剂（如 1 mol 某物最多与几 mol H₂ 加成，苯环算 3 mol）。
  • 除杂与分离：乙酸乙酯中除乙酸用饱和 Na₂CO₃ 溶液；溴苯中除溴用 NaOH 溶液；硝基苯中除硝酸用 NaOH 溶液。
  • 共线共面问题：苯环 12 原子共面、乙烯 6 原子共面、乙炔 4 原子共线，组合时注意单键可以旋转。

三、易错辨析

易混点辨析
卤代烃水解 vs 消去NaOH 水溶液加热 → 水解生成醇；NaOH 醇溶液加热 → 消去生成烯。条件决定产物
苯酚与羧酸的酸性苯酚酸性弱于碳酸（不能使石蕊变红），羧酸强于碳酸（能使石蕊变红）
酯化反应的水从哪来羧酸脱 —OH、醇脱 —H，用 ¹⁸O 标记可以证明
苯与烯烃的溴水反应苯不能使溴水褪色（只会萃取使水层变浅、苯层变橙），烯烃能使其褪色
口 诀 醇羟基能取代能消去能氧化，酚羟基显弱酸遇铁变紫，醛基能银镜能还原，羧基显酸能酯化。
苯环记三个字：易取代、难加成、不氧化。

四、例题精解

例　某有机物结构简式为 CH₂=CH—CH₂—COOH。判断 1 mol 该有机物分别与足量的 Br₂（水溶液）、H₂、NaHCO₃、Na 反应时，各消耗多少 mol？

Br₂ 水溶液：只有 C=C 加成，消耗 1 mol。

H₂：只有 C=C 加成，消耗 1 mol（—COOH 不与 H₂ 加成）。

NaHCO₃：—COOH 与 NaHCO₃ 反应放出 CO₂，1 mol —COOH 消耗 1 mol NaHCO₃。

Na：—OH 和 —COOH 都能与 Na 反应放出 H₂，但该分子只有 —COOH，1 mol 消耗 1 mol Na。

这类题的固定做法 把结构式里的官能团一个一个圈出来，逐个对照"能与谁反应、消耗几摩尔"，最后相加。不要凭整体感觉估。特别注意：苯环加 H₂ 是 3 mol；—COOH 不与 H₂ 加成；酚 —OH 与羧基都能与 Na 反应，但只有羧基能与 NaHCO₃ 反应。

五、分层练习

基础

1. 下列物质中，不能使溴水褪色的是（　）

A. 乙烯　B. 乙炔　C. 苯　D. 二氧化硫

答案与解析

C

苯不能与溴水反应，也不会使溴水褪色；把溴水中的溴萃取到苯层后，水层颜色变浅、苯层呈橙红色，但整体溴并未被消耗，属于"萃取"不是"褪色反应"。A、B 通过加成消耗 Br₂；D 中 SO₂ 把 Br₂ 还原为 Br⁻。

提升

2. 写出分子式为 C₄H₈ 的所有属于烯烃的同分异构体，并指出其中存在顺反异构的是哪一个。

答案与解析

共 3 种：1-丁烯、2-丁烯、2-甲基丙烯

① CH₂=CH—CH₂—CH₃（1-丁烯）
② CH₃—CH=CH—CH₃（2-丁烯）
③ CH₂=C(CH₃)₂（2-甲基丙烯，碳链异构）

只有 2-丁烯存在顺反异构：双键两端各连的基团不同（—CH₃ 和 —H），可以有顺式和反式两种。1-丁烯双键端基有两个 H，2-甲基丙烯双键端基有两个 H，都不满足顺反异构条件。

顺反异构的条件：双键两端每个碳上都连两个不同的基团。

选择性必修3 · 第四、五章有机合成 · 生物大分子 · 高分子

大题最后一问常写合成路线或判断单体，属于"送分但要完整"的分。

一、知识主线

1. 有机合成的思路

逆合成分析：从目标分子的结构出发，往回找它由什么反应得到，一步退到起点。常见连接方式：

目标结构常用形成方法
酯羧酸 + 醇，浓硫酸催化，可逆
碳碳双键卤代烃消去、醇消去
卤代烃烷烃取代、烯烃加成、醇取代
醚醇分子间脱水
肽键氨基酸缩合
官能团引入的先后顺序 合成中如果分子同时存在容易被氧化的基团（如酚羟基、醛基），需要先保护再反应、最后脱保护。题目里出现这类要求时，路线必须写出保护步骤，否则扣分。

2. 生物大分子

物质结构单元关键性质
糖类单糖（葡萄糖、果糖 C₆H₁₂O₆）、二糖（蔗糖、麦芽糖 C₁₂H₂₂O₁₁）、多糖（淀粉、纤维素）葡萄糖含 —CHO 能银镜；淀粉遇碘变蓝；淀粉和纤维素都水解成葡萄糖
油脂高级脂肪酸甘油酯碱性水解叫皂化反应；液态油加氢可变成固态脂肪（硬化油）
蛋白质氨基酸通过肽键缩合水解生成氨基酸；遇浓硝酸变黄（含苯环）；变性不可逆

氨基酸的特点：同一分子中既有 —NH₂ 又有 —COOH，能形成内盐，具有两性。

3. 高分子

类型特征实例
加聚反应单体含 C=C 或 C≡C，产物只有聚合物，无小分子脱落聚乙烯、聚丙烯、聚氯乙烯
缩聚反应单体有两个以上官能团，产物有聚合物和小分子（H₂O、HCl）聚酯（PET）、尼龙、酚醛树脂
找单体，两步 加聚物找单体：把主链上的碳碳键还原成双键（每两个碳为一组，双键写回去）。
缩聚物找单体：把酯基或肽键从中间断开，断处一端补 —OH、一端补 —H。

二、高频考点

  • 合成路线设计：给目标物和原料，写出中间步骤。常见套路是"烯烃 → 卤代烃 → 醇 → 醛 → 酸 → 酯"。
  • 单体与聚合物互推：给定聚合物写单体、或给定单体写聚合物。
  • 水解产物判断：糖类、油脂、蛋白质的完全水解产物。
  • 检验与鉴别：葡萄糖用银镜或新制 Cu(OH)₂；淀粉用碘水；蛋白质用浓硝酸或灼烧。

三、易错辨析

易混点辨析
糖类都是有甜味的纤维素、淀粉没有甜味；糖精有甜味但不是糖类
淀粉与纤维素是同分异构体？不是。两者通式都可写 (C₆H₁₀O₅)ₙ，但 n 值不同，聚合度不同，不互为同分异构体
油脂是高分子？不是。油脂相对分子质量较小，属于小分子化合物
加聚与缩聚的判断看有没有小分子生成，看单体是否只有双键
口 诀 糖类：单糖还原、二糖看是否还原（麦芽糖还原、蔗糖不还原）、多糖水解。
蛋白质：水解变氨基酸，变性不再回来，灼烧有焦臭味。

四、例题精解

例　某聚酯的结构为 —[O—CH₂—CH₂—O—CO—C₆H₄—CO]—ₙ（PET），写出它的两种单体，并说明反应类型。

第一步，判断类型。主链中存在酯基 —COO—，且以"断开—补基"的方式可以追到单体，属于缩聚反应。

第二步，从酯基处断开。酯基 —CO—O— 断开，羰基一方补 —OH，氧一方补 —H：

单体一：HO—CH₂—CH₂—OH（乙二醇）

单体二：HOOC—C₆H₄—COOH（对苯二甲酸）

第三步，验证。n 个乙二醇与 n 个对苯二甲酸缩聚，脱去 2n−1 个 H₂O，得到聚对苯二甲酸乙二醇酯。因为两种单体都是二官能团化合物，才能形成长链。

断键方向不要弄反 酯基中断裂的是 C—O 单键（羰基碳与氧之间），不是 C=O。断口处羰基侧补羟基、氧侧补氢，这样补回去正好是羧酸和醇。方向反了会补成醛和醚，一查就错。

五、分层练习

基础

1. 下列物质水解的最终产物只有一种的是（　）

A. 蔗糖　B. 麦芽糖　C. 蛋白质　D. 油脂

答案与解析

B

蔗糖水解生成葡萄糖和果糖，两种。麦芽糖水解只生成葡萄糖，一种。蛋白质水解生成多种氨基酸。油脂水解生成甘油和多种高级脂肪酸（或盐）。

提升

2. 以乙烯为原料（其他无机试剂任选），设计合成乙酸乙酯的路线，写出各步反应的化学方程式并注明反应类型。

答案与解析

路线：乙烯 → 乙醇 → 乙醛 → 乙酸 → 乙酸乙酯

① CH₂=CH₂ + H₂O --催化剂/加热加压--> CH₃CH₂OH　（加成）

② 2CH₃CH₂OH + O₂ --Cu/Δ--> 2CH₃CHO + 2H₂O　（氧化）

③ 2CH₃CHO + O₂ --催化剂/Δ--> 2CH₃COOH　（氧化）

④ CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O（浓硫酸，Δ）　（酯化/取代）

这条链是醇—醛—酸的经典转化，高考里出现频率极高。注意第③步也可用酸性 KMnO₄ 或银镜反应后的酸化，但工业上常用催化氧化。

跨册 · 通用化学实验

实验题是分值最重的一道大题，通常 14–16 分。考的不是背，而是"这一步为什么这么做"。

一、知识主线

1. 常用仪器与操作

操作关键点
过滤一贴二低三靠；沉淀要洗涤
蒸发结晶蒸发皿，玻璃棒搅拌，出现大量固体时停止加热，用余热蒸干
蒸馏温度计水银球在蒸馏烧瓶支管口处；冷凝水下进上出

2. 常见气体的实验室制法

气体反应物收集方法干燥剂
O₂KClO₃ + MnO₂ 加热；或 H₂O₂ + MnO₂排水法或向上排空气浓硫酸
Cl₂MnO₂ + 浓盐酸，加热向上排空气（或排饱和食盐水）浓硫酸

3. 实验设计与评价

四个必答的"为什么" 为什么先通一段时间气体再加热？排尽装置内空气，防止爆炸或氧化。
为什么要有防倒吸装置？易溶气体（NH₃、HCl）被吸收时压强骤降，液体会倒吸。
为什么末端要有尾气处理？有毒气体（Cl₂、SO₂、NO₂、CO）不能直接排空。
为什么要在装置之间加干燥或除杂？杂质会干扰后续检验或反应。

二、高频考点

  • 装置连接顺序：发生 → 除杂 → 干燥 → 主体反应 → 收集 → 尾气处理。干燥和除杂的先后要看除杂试剂是不是水溶液。
  • 物质检验的方案设计：先说取样、加试剂、看现象、得结论，四句话写全。特别注意"排除干扰"这一步是得分点。
  • 定量实验误差分析：明确测什么、由什么量算出、哪个步骤会让这个量偏大或偏小。
  • 气密性检查：微热法或液差法，答题格式是"……后，若……，则气密性良好"。

三、易错辨析

易混点辨析
排水法与排空气法能用排水法的前提是气体不溶于水且不与水反应。NO₂、NH₃、HCl 不能用排水法
干燥剂的选择浓硫酸不能干燥 NH₃；碱石灰不能干燥 CO₂、SO₂、Cl₂；无水 CaCl₂ 不能干燥 NH₃
检验 SO₄²⁻ 先加什么先加稀盐酸，不是稀硝酸，也不是氯化钡（先加 BaCl₂ 会把 Ag⁺ 等干扰带进来）
洗涤沉淀用什么用蒸馏水或乙醇，不能用滤液（会把杂质带回来）
口 诀 装置顺序：发生—除杂—干燥—主体—收集—尾气。
检验四句话：取少量、加试剂、说现象、下结论。少一句都要扣分。

四、例题精解

例　用下图思路制取并收集干燥纯净的氯气：MnO₂ 与浓盐酸共热 → 饱和食盐水 → 浓硫酸 → 向上排空气收集 → NaOH 溶液吸收尾气。回答：

(1) 饱和食盐水的作用是什么？(2) 为什么用向上排空气法收集？(3) 尾气为什么必须处理？

(1) 除去 Cl₂ 中混有的 HCl 气体。Cl₂ 在饱和食盐水中溶解度很小（同离子效应），损失可忽略，而 HCl 极易溶被吸收。

(2) Cl₂ 的密度比空气大（相对分子质量 71 > 29），且能与水反应，所以不能用排水法。

(3) Cl₂ 有毒，直接排放会污染空气，用 NaOH 溶液吸收：Cl₂ + 2NaOH = NaCl + NaClO + H₂O。

顺序不能颠倒 如果先浓硫酸再饱和食盐水，气体通过食盐水时又会带出水蒸气，前面的干燥白做。凡"除杂 + 干燥"同时出现，除杂（水溶液）一定在干燥之前。

五、分层练习

基础

1. 下列气体中，不能用浓硫酸干燥的是（　）

A. Cl₂　B. SO₂　C. NH₃　D. CO₂

答案与解析

C

NH₃ 是碱性气体，会与浓硫酸反应生成 (NH₄)₂SO₄，所以不能用浓硫酸干燥，应改用碱石灰。其余三种都是酸性或中性气体，可用浓硫酸干燥。

提升

2. 设计实验证明某白色固体中含有 Na₂CO₃ 和 NaCl，写出操作步骤、现象和结论。

答案与解析

步骤 1：取少量固体溶于水配成溶液，加入足量稀硝酸，产生气泡，说明含 CO₃²⁻。

步骤 2：将上述溶液煮沸赶尽 CO₂（或用足量稀硝酸酸化），再滴加 AgNO₃ 溶液，产生白色沉淀，说明含 Cl⁻。

结论：固体中含 Na₂CO₃ 和 NaCl。

关键点：必须先加足量稀硝酸排除 CO₃²⁻ 的干扰（Ag₂CO₃ 也是白色沉淀），否则无法证明 Cl⁻ 的存在。用稀盐酸也不行，因为引入了 Cl⁻。

跨册 · 通用化学与 STSE

选择题第一题的位置，3–6 分。背不背差别很大，但量不大。

主题必记内容
能源化石燃料（煤、石油、天然气）不可再生；新能源有太阳能、风能、核能、氢能、生物质能。氢能热值高、产物只有水
环境酸雨主要成分 SO₂ 和 NOₓ（pH < 5.6）；光化学烟雾来自氮氧化物和碳氢化合物；臭氧层空洞与氟氯代烷有关；温室效应主要是 CO₂ 和 CH₄；水体富营养化是氮磷过量导致
材料三大传统材料：水泥、玻璃、陶瓷。三大合成材料：塑料、合成纤维、合成橡胶。合金硬度大于成分金属，熔点更低
健康食盐加碘（KIO₃）防甲状腺肿大；缺铁导致贫血；维生素 C 有还原性，可作抗氧化剂；甲醛、亚硝酸钠有毒或致癌

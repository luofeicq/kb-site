# 高中知识库 · 物理 化学 生物

给高中生复习和查知识点用的静态站点，纯前端、零外部依赖。

**线上地址：** https://luofeicq.github.io/kb-site/

## 结构

```
index.html      门户：全站搜索 + 三科入口 + 知识地图（33 章一览）
physics.html    物理（6 个专题 + 2 个附录）
chem.html       化学（13 章）
bio.html        生物（12 章）

shell.js        站点外壳：顶栏 / 搜索面板 / 进度条 / 返回顶部
kb-index.js     全站搜索索引（33 条，构建时从 HTML 自动提取）
```

三个学科页共用同一套顶栏与搜索，各自内联样式，互不依赖。

## 搜索

- 按 `/` 或点顶栏搜索框唤起，`Ctrl/Cmd + K` 也可
- `↑` `↓` 选择，`Enter` 打开，`Esc` 关闭
- 跨三科检索，整词优先；整词无果时按两字片段兜底（如“遗传规律”可命中“遗传基本规律与伴性遗传”）
- 结果按“章名命中 → 章号命中 → 词频”排序

交互图全部 canvas 手绘，无图表库、无网络请求。

## 重新构建

```bash
python build_site.py      # 重新提取索引并注入顶栏样式（幂等）
```

改完内容后同步母版并推送即可，Pages 约 25 秒后生效。

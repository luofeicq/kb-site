必修1 · 第1章细胞的分子组成

高考直接考的不多（3–6 分），但它是理解代谢、遗传的前提。选择题里"下列叙述正确的是"这类题，八成从这里出。

一、知识主线

1. 元素与化合物

细胞中含量最多的元素是 O（按质量）或 H（按原子数）；最基本的元素是 C，因为碳链构成有机物骨架。大量元素有 C、H、O、N、P、S、K、Ca、Mg 等，微量元素有 Fe、Mn、Zn、Cu、B、Mo 等。

化合物质量分数核心作用
水85%–90%含量最多；溶剂、运输、参与反应
蛋白质7%–10%生命活动的主要承担者
脂质1%–2%储能、构成膜、调节
糖类与核酸各 1%–1.5%糖类是主要能源；核酸是遗传物质

2. 水与无机盐

形式作用变化规律
自由水细胞内良好溶剂，运输物质，参与化学反应，提供液体环境自由水/结合水比值升高 → 代谢旺盛；比值降低 → 抗逆性增强（如越冬植物、休眠种子）
结合水细胞结构的重要组成成分与自由水可相互转化

无机盐多以离子形式存在。功能有三：构成细胞结构（如 Mg²⁺ 构成叶绿素、Fe²⁺ 构成血红蛋白）、维持细胞和生物体的生命活动（如 Ca²⁺ 过低引起抽搐）、维持渗透压和酸碱平衡。

3. 糖类与脂质

类别种类要点
单糖葡萄糖、果糖、核糖、脱氧核糖葡萄糖是"生命的燃料"；核糖参与 RNA
二糖蔗糖、麦芽糖（植物）；乳糖（动物）蔗糖水解成葡萄糖 + 果糖
多糖淀粉、纤维素（植物）；糖原（动物）纤维素不能被人消化，但能促进肠道蠕动（膳食纤维）
脂肪甘油 + 脂肪酸储能物质，同质量下比糖类储能多一倍以上
磷脂甘油 + 脂肪酸 + 磷酸构成细胞膜的基本骨架
固醇胆固醇、性激素、维生素 D胆固醇参与构成动物细胞膜，还参与脂质运输

4. 蛋白质：结构决定功能

氨基酸的结构通式：一个碳原子上连着氨基（—NH₂）、羧基（—COOH）、氢原子和一个侧链基团（R 基）。不同氨基酸的差别只在 R 基。

肽键数 = 脱去的水分子数 = 氨基酸数 − 肽链数
项目要点
结构多样性原因氨基酸的种类、数目、排列顺序不同，肽链的盘曲折叠方式及空间结构不同
功能多样性结构蛋白（肌肉、羽毛）、催化（酶）、运输（血红蛋白）、调节（胰岛素）、免疫（抗体）
变性高温、强酸强碱、重金属使空间结构破坏，肽键不断裂，不可逆

5. 核酸

DNARNA
五碳糖脱氧核糖核糖
特有碱基T（胸腺嘧啶）U（尿嘧啶）
共有碱基A、G、C
基本单位脱氧核苷酸（4 种）核糖核苷酸（4 种）

二、高频考点

  • 有机物检测实验：还原糖 + 斐林试剂 → 水浴加热 → 砖红色沉淀；蛋白质 + 双缩脲试剂 → 紫色（不加热）；脂肪 + 苏丹Ⅲ → 橘黄色（需显微镜）；淀粉 + 碘 → 蓝色。
  • 蛋白质计算：n 个氨基酸形成 m 条肽链，肽键数 = n − m，相对分子质量减少 18(n−m)。若含二硫键，每形成一个 —S—S— 再减少 2。
  • 自由水与代谢的关系：凡是"代谢旺盛"的叙述（萌发种子、癌细胞、年幼细胞），自由水/结合水比值都高。

三、易错辨析

易混点辨析
斐林试剂与双缩脲试剂成分相同（NaOH 和 CuSO₄），但浓度和用法不同：斐林试剂要甲液乙液等量混合后使用并水浴加热；双缩脲试剂先加 A 液再加 B 液，不加热
脂质都是脂肪？不是。脂质包括脂肪、磷脂、固醇三类，磷脂和固醇不是脂肪
糖类是唯一能源？糖类是主要能源物质，但脂肪是主要储能物质，蛋白质在特殊情况下也供能
蛋白质变性后肽键断裂？没有。变性只破坏空间结构，肽键完好，所以变性蛋白仍能与双缩脲试剂反应
口 诀 检测记"糖加热、蛋白不加热"。
水的规律记"自由多代谢旺，结合多抗逆强"。

四、例题精解

例　某蛋白质由 2 条肽链构成，共含 128 个氨基酸，其中有一个二硫键（—S—S—）。求：① 该蛋白质形成时脱去的水分子数；② 相对分子质量比原来减少了多少？

① 脱水数：肽键数 = 氨基酸数 − 肽链数 = 128 − 2 = 126，所以脱去 126 个水分子。

② 减少的相对分子质量：脱水减少 126 × 18 = 2268。形成 1 个二硫键还要脱去 2 个 H，再减少 2。合计 2268 + 2 = 2270。

两个坑 ① 忘了减肽链数，直接算成 128 个水；② 忘了二硫键。题目里只要出现"—S—S—"，就要在失水总量上再加 2（每个二硫键）。

五、分层练习

基础

1. 下列关于细胞中水的叙述，正确的是（　）

A. 自由水是细胞结构的重要组成成分

B. 结合水越多，细胞代谢越旺盛

C. 越冬植物细胞内自由水与结合水的比值会降低

D. 水在细胞中都以自由水的形式存在

答案与解析

C

结合水才是结构组成成分，A 错。自由水越多代谢越旺盛，B 反了。水有自由水和结合水两种形式，D 错。越冬时自由水减少、结合水相对增多，比值降低，抗寒能力增强，C 对。

提升

2. 现有 100 个氨基酸，共含 110 个氨基和 118 个羧基，由这些氨基酸缩合成一条多肽链。求该多肽链中游离的氨基和羧基的数目。

答案与解析

游离氨基 11 个，游离羧基 19 个

一条肽链至少有一端游离氨基、一端游离羧基。R 基上的氨基数 = 110 − 100 = 10（每个氨基酸至少 1 个氨基，多出的都在 R 基）。R 基上的羧基数 = 118 − 100 = 18。

所以游离氨基 = 1（肽链一端）+ 10 = 11；游离羧基 = 1 + 18 = 19。

必修1 · 第2、3章细胞的结构与功能

细胞器功能与分泌蛋白的合成运输是高频选择题，几乎每套卷都有。

一、知识主线

1. 细胞膜

流动镶嵌模型：磷脂双分子层构成基本骨架，蛋白质镶在表面、嵌入或贯穿其中，外表面还有糖蛋白（糖被）。结构特点是一定的流动性，功能特性是选择透过性。

三大功能：将细胞与外界环境分隔开、控制物质进出细胞、进行细胞间的信息交流。

3. 细胞核

核膜（双层）、核孔、核仁、染色质。核孔是大分子物质进出细胞核的通道（如 mRNA 出核、蛋白质入核），但 DNA 不能通过核孔。核仁与核糖体的形成有关。染色质和染色体是同种物质在不同时期的两种形态。

4. 分泌蛋白的合成与运输

核糖体 → 内质网（加工、折叠）→ 高尔基体（进一步加工、分类包装）→ 细胞膜（胞吐）

全程需要线粒体供能。这一过程中，内质网的膜面积减少、高尔基体的膜面积先增后减、细胞膜的膜面积增加。

二、高频考点

  • 细胞器功能的对应：给一段功能描述，判断是哪个细胞器。记住关键词：加工、分类、包装 → 高尔基体；合成蛋白质 → 核糖体；消化 → 溶酶体；调节渗透压 → 液泡。
  • 分泌蛋白路径的放射性追踪：给 ³H 标记的氨基酸，问放射性依次出现在哪些结构。
  • 细胞膜的结构与功能：常考"糖被只分布在细胞膜外侧"、"载体蛋白具有特异性"。

三、易错辨析

易混点辨析
核糖体与内质网的功能核糖体只负责"合成"，加工在内质网。游离核糖体合成胞内蛋白，附着核糖体合成分泌蛋白
溶酶体的酶从哪来由核糖体合成、经内质网和高尔基体加工后形成，不是溶酶体自己合成的
细胞壁的成分植物细胞壁是纤维素和果胶（高尔基体参与形成）；细菌细胞壁是肽聚糖；真菌是几丁质
核孔是否"什么都过"核孔有选择性，DNA 不能通过，mRNA 和蛋白质可以通过
口 诀 膜层数：双膜线叶、单膜内高液溶、无膜核糖中心。
分泌蛋白：核（糖体）内（质网）高（尔基）膜，四步走，线粒体全程供能。

四、例题精解

例　用 ³H 标记的亮氨酸培养胰腺腺泡细胞，追踪放射性出现的顺序。下列排序正确的是（　）

A. 核糖体 → 内质网 → 高尔基体 → 细胞膜　B. 核糖体 → 高尔基体 → 内质网 → 细胞膜

C. 内质网 → 核糖体 → 高尔基体 → 细胞膜　D. 高尔基体 → 内质网 → 核糖体 → 细胞膜

答案：A。

推理：亮氨酸是合成蛋白质的原料，最先在核糖体上脱水缩合形成肽链。肽链进入内质网进行初步加工、折叠，再经囊泡运输到高尔基体进一步加工、分类、包装，最后由囊泡运至细胞膜，通过胞吐分泌到细胞外。

注意两个细节 ① 胰岛素、抗体、消化酶都是分泌蛋白，走这条路径；血红蛋白、呼吸酶是胞内蛋白，不走这条路。
② 题目若问"经过哪些细胞器"，答案里应包含核糖体、内质网、高尔基体、线粒体；若问"经过哪些膜结构"，核糖体无膜，不能算进去。

A. 线粒体　B. 核糖体　C. 高尔基体　D. 溶酶体

答案与解析

提升

2. 分泌蛋白从合成到分泌的过程中，内质网膜、高尔基体膜、细胞膜的膜面积分别如何变化？

答案与解析

内质网膜面积减小，高尔基体膜面积基本不变，细胞膜面积增大

内质网以出芽方式形成囊泡，膜面积减少；高尔基体接受囊泡（膜增加）又出芽形成囊泡（膜减少），一进一出面积基本不变；囊泡与细胞膜融合，使细胞膜面积增大。

这条"膜面积变化"是分泌蛋白专题的固定考点，答"高尔基体不变"是关键。

必修1 · 第4章物质跨膜运输 · 酶 · ATP

选择题常考"运输方式的判断"和"酶的特性曲线"。三个知识点合在一起，是因为它们都属于"细胞代谢的条件"。

一、知识主线

1. 三种跨膜运输方式

方式是否需要载体是否耗能方向实例
自由扩散否否高浓度 → 低浓度O₂、CO₂、甘油、乙醇、苯
协助扩散是否高浓度 → 低浓度葡萄糖进入红细胞、水通道
主动运输是是可逆浓度梯度K⁺、Na⁺、氨基酸、葡萄糖进入小肠上皮细胞

胞吞胞吐不属于跨膜运输（物质不穿过膜，靠膜的流动性），但也要消耗能量。

判断运输方式的三连问 ① 有没有载体？（看是否饱和、是否有竞争抑制、是否受载体抑制剂影响）
② 耗不耗能？（缺氧或加呼吸抑制剂后是否受影响）
③ 逆不逆浓度？（低浓度侧能否继续吸收）

2. 酶

酶是活细胞产生的具有催化作用的有机物，绝大多数是蛋白质，少数是 RNA。三个特性：高效性、专一性、作用条件较温和。

因素影响机理曲线特征
温度低温抑制活性（可恢复），高温使酶变性（不可恢复）先升后降，有一个最适温度
pH过酸过碱都使酶变性钟形曲线，有一个最适 pH
底物浓度底物有限时限制速率，过量后受酶量限制先近线性上升，后趋于平台
酶浓度底物充足时正比过原点的直线

3. ATP

ATP ⇌ ADP + Pi + 能量　　（A—P~P~P，"~"是高能磷酸键）

ATP 是直接能源物质。合成 ATP 的途径：细胞呼吸（所有活细胞）、光合作用（绿色植物）。ATP 水解释放的能量用于各项生命活动。

注意：ATP 在细胞中含量很少，但转化速度极快，能保证能量的持续供应。

二、高频考点

  • 运输方式的实验判断：给一组数据（如某物质在细胞内外的浓度），判断是主动运输还是被动运输。
  • 酶促反应曲线分析：改变温度/pH 时，最适点是否移动；改变酶浓度时，最大速率变化但最适条件不变。
  • ATP 与能量代谢的关系：ATP 水解释放的能量可转化为机械能、电能、渗透能、化学能等。

三、易错辨析

易混点辨析
低温与高温对酶的影响低温只是降低活性，回温后恢复；高温破坏空间结构，不可恢复。所以酶制剂要低温保存
酶 vs 激素酶有催化作用，反应前后自身不变；激素起调节作用，起作用后被灭活
协助扩散需要能量？不需要。只有主动运输和胞吞胞吐消耗 ATP
ATP 中的"A"是腺苷（腺嘌呤 + 核糖），不是腺嘌呤
口 诀 运输三问：要载体吗？要能量吗？逆浓度吗？三个"是"→主动运输；前两个"否"→自由扩散；只有中间"是"→协助扩散。
酶：低温不坏，高温变坏，过酸过碱也变坏。

四、例题精解

例　某植物根细胞对 K⁺ 的吸收速率随 O₂ 浓度变化的曲线是：O₂ 浓度为 0 时仍有少量吸收，随 O₂ 浓度升高吸收速率增大，之后趋于稳定。说明 K⁺ 进入根细胞的方式是什么？为什么？

答案：主动运输。

理由一：O₂ 浓度为 0 时仍能吸收，说明不完全是需氧供能的过程，但吸收速率随 O₂ 浓度升高而增大，说明该过程需要能量（有氧呼吸供能）。

理由二：吸收速率最终趋于稳定，是因为载体蛋白数量有限，说明需要载体。

既需要载体又需要能量，且根细胞能从土壤中低浓度的 K⁺ 持续吸收，属于逆浓度梯度的主动运输。

曲线题的读图顺序 先看起点（是否为零 → 是否完全依赖该因素）、再看趋势（升/降/平台）、最后看平台（说明什么受限）。这题的"平台"就是载体饱和，"起点不为零"说明还有无氧呼吸供能。两步就能说清。

基础

1. 下列物质进出细胞的方式中，需要载体蛋白但不消耗能量的是（　）

A. 葡萄糖进入红细胞　B. 葡萄糖进入小肠上皮细胞

C. 氧气进入肺泡细胞　D. 白细胞吞噬细菌

答案与解析

A

葡萄糖进入红细胞是协助扩散，需要载体不耗能。葡萄糖进入小肠上皮细胞是主动运输，耗能。氧气是自由扩散，不需要载体。白细胞吞噬细菌是胞吞，需要能量但不属于跨膜运输。

提升

2. 某同学做"探究温度对淀粉酶活性的影响"实验，先将淀粉酶与淀粉分别保温在不同温度下，再混合。若要检测结果，能否用斐林试剂？为什么？

答案与解析

不能，应改用碘液

斐林试剂检测还原糖需要水浴加热，而加热会改变酶已经设定的温度条件，使实验变量失控——低温组的酶在检测时会因加热而恢复活性，结果失真。碘液在常温下检测淀粉是否被分解，不影响温度变量。

这是实验设计题里很典型的一处"检测方法反过来干扰自变量"的错误。

必修1 · 第5章细胞呼吸与光合作用

必修一的核心，也是整卷最容易出大题的地方。两条主线必须能默写，曲线必须能分析。

一、知识主线

1. 有氧呼吸三阶段

阶段场所反应产物
第一阶段（糖酵解）细胞质基质葡萄糖 → 2 丙酮酸 + 4[H]少量 ATP
第二阶段线粒体基质2 丙酮酸 + 6H₂O → 6CO₂ + 20[H]少量 ATP
第三阶段线粒体内膜24[H] + 6O₂ → 12H₂O大量 ATP
C₆H₁₂O₆ + 6O₂ + 6H₂O --酶--> 6CO₂ + 12H₂O + 能量

无氧呼吸：第一阶段同上，第二阶段丙酮酸在细胞质基质中转化为乳酸或酒精 + CO₂。只在第一阶段产生少量 ATP。微生物的无氧呼吸也叫发酵。

2. 光合作用

阶段场所物质变化能量变化
光反应类囊体薄膜水的光解产生 [H] 和 O₂；ADP + Pi → ATP光能 → 活跃化学能
暗反应（碳反应）叶绿体基质CO₂ 固定形成 C₃；C₃ 被 [H] 还原，一部分生成糖类，一部分再生 C₅活跃化学能 → 稳定化学能
6CO₂ + 12H₂O --光能/叶绿体--> C₆H₁₂O₆ + 6O₂ + 6H₂O
条件突变时的瞬时变化，记住这条推理链 光照突然减弱 → [H] 和 ATP 减少 → C₃ 还原受阻 → C₃ 增多、C₅ 减少；同时 CO₂ 固定仍在进行，短暂消耗 C₅。
CO₂ 突然减少 → C₃ 生成减少 → C₃ 减少、C₅ 增多，[H] 和 ATP 暂时积累。
判断口诀：先看谁变，再看它被谁用、用来生成谁。

图 4-1　光合曲线：光强、CO₂ 怎么影响净光合

可操作
拖光强滑块，看净光合速率怎么走。曲线与横轴的交点是光补偿点（光合 = 呼吸，净积累为 0），再往右到平台是光饱和点。切 CO₂ 浓度，整条曲线会抬高或压低，但光补偿点几乎不动。

二、高频考点

  • 总光合与净光合的换算：净光合 = 总光合 − 呼吸。测"吸收 CO₂ 的量"是净光合，测"制造有机物的量"是总光合。
  • 密闭容器中 CO₂ 浓度变化曲线：下降段表示光合 > 呼吸，转折点是补偿点。
  • 呼吸速率的测定：用 NaOH 吸收 CO₂，测 O₂ 的减少量；或遮光测 CO₂ 释放量。
  • 同位素标记追踪：¹⁴C 标记 CO₂，追踪 C 的转移途径：CO₂ → C₃ → 有机物。

三、易错辨析

易混点辨析
光合作用的 O₂ 来自 CO₂？来自水。用 H₂¹⁸O 标记可证明释放的 O₂ 含 ¹⁸O
[H] 是同一种物质？光合作用产生的 [H] 是 NADPH，呼吸作用产生的是 NADH，不是同一种
无氧呼吸不产生 ATP？第一阶段产生少量 ATP，只是第二阶段不产生
暗反应不需要光？暗反应本身不直接需要光，但需要光反应提供的 [H] 和 ATP，长期无光则停止
口 诀 有氧呼吸三阶段：一在质、二在基、三在内膜，能量少、少、多。
光合两阶段：光反应在膜上，暗反应在基质；光反应产 [H] 和 ATP，暗反应用它们还原 C₃。

四、例题精解

例　将某绿色植物置于密闭容器中，黑暗处理 1 h 后测得 CO₂ 增加 22 mg；随后给予适宜光照 1 h，测得 CO₂ 减少 44 mg。求：① 呼吸速率；② 光照 1 h 的净光合速率与总光合速率（以 CO₂ mg/h 表示）。

① 呼吸速率：黑暗下只进行呼吸作用，CO₂ 增加量即呼吸释放量，22 mg/h。

② 净光合速率：光照下 CO₂ 减少量 = 净光合吸收量 = 44 mg/h。

③ 总光合速率：总光合 = 净光合 + 呼吸 = 44 + 22 = 66 mg/h。

三个概念必须分清 "CO₂ 减少量"是净光合；"CO₂ 固定量"或"制造有机物量"是总光合；呼吸速率无论光暗都在进行。题目给的数字属于哪一个，决定了要不要加呼吸。
另外注意单位：mg/h 是速率，mg 是总量，问"速率"时不要漏掉时间。

五、分层练习

基础

1. 有氧呼吸过程中，产生 ATP 最多的阶段和产生 CO₂ 的阶段分别是（　）

A. 第一阶段、第一阶段　B. 第三阶段、第二阶段

C. 第二阶段、第三阶段　D. 第三阶段、第一阶段

答案与解析

B

第三阶段 [H] 与 O₂ 结合生成水，释放大量能量，产生 ATP 最多。CO₂ 在第二阶段（线粒体基质中丙酮酸与水反应）产生。

提升

2. 其他条件不变，突然停止光照，短时间内叶绿体中 C₃、C₅、[H] 和 ATP 的含量分别如何变化？

答案与解析

C₃ 增多，C₅ 减少，[H] 减少，ATP 减少

停止光照后，光反应停止，[H] 和 ATP 不再生成，被暗反应继续消耗，所以两者都减少。

C₃ 的还原因缺少 [H] 和 ATP 而受阻，C₃ 消耗减少、积累增多；同时 CO₂ 固定仍在进行，继续消耗 C₅ 生成 C₃，所以 C₅ 减少。

推理的关键是"反应仍在进行，只是某一环节被卡住"，不是所有反应同时停止。

1. 细胞周期

四、例题精解

例　某动物（2n = 4）的精原细胞进行减数分裂。不考虑交叉互换，回答：① 减Ⅰ后期的细胞中有几条染色体、几个 DNA、几条染色单体？② 一个精原细胞最终产生几种精子？

① 减Ⅰ后期：同源染色体正在分离，但细胞还没分裂，染色体数仍为 4 条，DNA 为 8 个，染色单体为 8 条（每条染色体含 2 条姐妹染色单体）。

② 精子种类：该细胞含 2 对同源染色体，减Ⅰ时非同源染色体自由组合产生 2 种组合，因此形成 2 种精子（每种 2 个）。

延伸：如果题目问"该动物产生的精子种类"，则要考虑多个精原细胞，理论上有 2² = 4 种。问"一个精原细胞"和"一个个体"的答案不同，这是最常见的失分点。

必修2 · 第1、2章遗传基本规律与伴性遗传

遗传题是大题固定位置，分值高。棋盘、比例、系谱三块必须熟到能反应。

一、知识主线

1. 一对相对性状的杂交实验

P：高茎 × 矮茎 → F₁ 全为高茎 → F₂ 高茎 : 矮茎 = 3 : 1

孟德尔用假说—演绎法：提出问题 → 作出假说（体细胞中遗传因子成对、形成配子时成对因子分离）→ 演绎推理（测交应为 1:1）→ 实验验证 → 得出结论。

2. 分离定律与自由组合定律

定律内容发生时期典型比例
分离定律等位基因随同源染色体的分开而分离减Ⅰ后期3 : 1（杂合自交）、1 : 1（测交）
自由组合定律非同源染色体上的非等位基因自由组合减Ⅰ后期9 : 3 : 3 : 1（双杂合自交）

3. 伴性遗传

类型特点实例
X 染色体隐性男性患者多于女性；交叉遗传（外公 → 母亲 → 外孙）；女患者的父亲和儿子必患病红绿色盲、血友病

二、高频考点

  • 显隐性与基因位置的判断：自交看是否发生性状分离（有分离则显性为亲本性状）；测交看比例。
  • 基因定位：判断基因在常染色体还是 X 染色体上，常考"隐性雌 × 显性雄"是否出现交叉遗传。
  • 自由组合的变形比：9:7、9:6:1、15:1、9:3:4 都是 9:3:3:1 的变体，本质是基因互作，仍按两对基因独立遗传来算。
  • 概率计算：先拆成一对一对算，再相乘（乘法原理）。

三、易错辨析

易混点辨析
3 : 1 与 1 : 13:1 是杂合子自交，1:1 是杂合子测交。看的是"自交"还是"与隐性纯合杂交"
基因自由组合 = 性状自由组合？只有位于非同源染色体上的非等位基因才自由组合；同一条染色体上的基因连锁
伴 X 隐性遗传中"女患者"的条件女儿患病，父亲一定患病、儿子一定患病，这是判断系谱的关键
表现型相同基因型相同？不一定，如显性性状可能是 AA 也可能是 Aa
口 诀 分离定律：一对基因三比一，测交一半对一半。
自由组合：两对基因九三三一；变形比先加起来看总和是不是 16。
伴 X 隐性：母病子必病，女病父必病。

四、例题精解

例　豌豆的高茎（D）对矮茎（d）为显性，圆粒（R）对皱粒（r）为显性，两对基因独立遗传。让 DdRr × DdRr 杂交，求：① 子代中高茎圆粒的比例；② 子代中纯合子的比例；③ 子代中与亲本表现型相同的比例。

先拆成一对待一对。Dd × Dd → 高茎 3/4、矮茎 1/4；Rr × Rr → 圆粒 3/4、皱粒 1/4。

① 高茎圆粒：3/4 × 3/4 = 9/16。

② 纯合子：每对中纯合子占 1/2（DD + dd = 1/4 + 1/4），两对都是纯合子 = 1/2 × 1/2 = 1/4。

③ 与亲本表现型相同（高茎圆粒）：就是 ①，9/16。

别急着画棋盘 两对基因独立遗传时，先算每一对的分离比，再用乘法原理相乘，比画 16 格棋盘快得多，也不容易漏。棋盘只用来验算或讲清原理。
只有遇到"基因互作"（如 9:7、15:1）或需要列出具体组合时，才回到棋盘。

2. DNA 的结构与复制

双螺旋结构：两条反向平行的脱氧核苷酸链，碱基通过氢键配对（A—T 两个氢键，G—C 三个氢键），磷酸和脱氧核糖交替排列在外侧构成基本骨架。

项目要点
复制时间细胞分裂间期
复制方式半保留复制，边解旋边复制
条件模板（DNA 双链）、原料（4 种脱氧核苷酸）、能量（ATP）、酶（解旋酶、DNA 聚合酶）
碱基计算A = T，G = C；(A+T)/(G+C) 在双链与单链中相同，(A+G)/(T+C) 双链中恒为 1

四、例题精解

例　某双链 DNA 分子中，A 占全部碱基的 30%，其中一条链（称为 α 链）上 G 占该链碱基的 20%。求：① 该 DNA 中 G 的比例；② α 链上 A 的比例范围无法确定，但 β 链上 G 的比例是多少？

① 双链中 A = T = 30%，所以 A + T = 60%，G + C = 40%，G = C = 20%。

② 设 α 链碱基数为 100，则 β 链也是 100，双链共 200 个碱基，G 总数为 20% × 200 = 40 个。

α 链上 G = 20% × 100 = 20 个，剩下的 40 − 20 = 20 个 G 全在 β 链上，占 β 链的 20%。

碱基计算的通用思路 ① 双链中 A = T、G = C；② 一条链上的 A 等于另一条链上的 T；③ 算总数比算比例稳——先把"双链总数"设成 200，再把各链加起来，不容易乱。
题目若给"A 占 30%，G 占 20%"，一定先检查加起来是否合逻辑（A+T+G+C 应等于 100%）。

四、例题精解

例　某植物种群中，AA 个体占 30%，Aa 占 60%，aa 占 10%。若该种群随机交配，子一代中 A 的基因频率是多少？aa 的基因型频率是多少？

第一步，算基因频率。设种群有 100 个个体，则 A 基因数 = 30×2 + 60×1 = 120，等位基因总数 = 200。

p(A) = 120/200 = 0.6　　q(a) = 1 − 0.6 = 0.4

第二步，随机交配后。随机交配不改变基因频率，子一代中 A 仍为 0.6、a 为 0.4。

aa = q² = 0.4² = 0.16，即 16%

答案：A 基因频率 0.6，子一代 aa 占 16%。

随机交配与自交的区别 随机交配后基因频率和基因型频率都不再变化（达到哈代-温伯格平衡）；连续自交则基因频率不变、纯合子比例升高、杂合子比例降低。这两句话每年都考，一定要分开记。
这题如果改成"自交"，aa 的比例就要按 1/4 × 60% + 10% = 25% 计算，答案完全不同。

例　给离体的神经纤维施加一个适宜刺激，测得膜电位变化如图（先上升到 +30 mV，再下降到 −70 mV 以下，最后回到 −70 mV）。回答：① 静息电位数值是多少？② 电位上升到 +30 mV 的主要原因是什么？③ 若降低细胞外 Na⁺ 浓度，动作电位的峰值会怎样变化？

这条推理每年都考 细胞外 Na⁺ 浓度 ↓ → 动作电位峰值 ↓，但静息电位基本不变；
细胞外 K⁺ 浓度 ↑ → 静息电位绝对值 ↓（更接近 0），动作电位峰值影响较小。

效应物质抗体效应 T 细胞直接接触靶细胞
结果抗原被抗体结合后形成沉淀或细胞集团，被吞噬细胞清除靶细胞裂解死亡，病原体暴露后被抗体或吞噬细胞清除

两条路线不是孤立的：多数病原体感染时两者协同，T 细胞还能分泌淋巴因子促进 B 细胞增殖分化。

3. 二次免疫

初次免疫产生记忆细胞，再次接触同一抗原时，记忆细胞迅速增殖分化为浆细胞，产生抗体又快又多。这是疫苗接种的原理。

4. 免疫失调

类型机理实例
过敏反应已免疫的机体再次接触过敏原时发生的组织损伤或功能紊乱花粉过敏、青霉素过敏
自身免疫病免疫系统攻击自身正常组织类风湿性关节炎、系统性红斑狼疮
免疫缺陷病免疫功能低下或缺失艾滋病（HIV 攻击 T 细胞）

二、高频考点

  • 抗体与抗原的关系：抗体由浆细胞产生，一种浆细胞只产生一种抗体，但一种抗原可刺激产生多种抗体。
  • 二次免疫曲线：与初次相比，抗体出现更早、峰值更高、持续时间更长。
  • 艾滋病：HIV 主要攻击 T 细胞，导致免疫功能几乎全部丧失，患者常死于其他感染或肿瘤。
  • 器官移植：使用免疫抑制剂抑制排斥反应，但会增加感染风险。

三、易错辨析

易混点辨析
浆细胞与 B 细胞B 细胞能识别抗原并增殖分化；浆细胞不能识别抗原，只负责产生抗体
抗体能直接杀死病原体？不能。抗体只是与抗原结合，最终靠吞噬细胞清除
过敏反应是免疫功能过强？是免疫功能异常（免疫系统对无害物质反应过度），不是简单的"过强"
T 细胞只在细胞免疫中起作用？T 细胞也参与体液免疫（分泌淋巴因子促进 B 细胞分化）
口 诀 两条路线：体液免疫靠抗体打"外面"的，细胞免疫靠效应 T 打"里面"的。
记住两个"不能"：浆细胞不能识别抗原，抗体不能直接消灭抗原。

四、例题精解

例　某同学接种了新冠疫苗，一个月后再次接触同种病原体。与初次接触相比，体内抗体的产生有什么特点？为什么？

特点：抗体产生更快、浓度更高、持续时间更长。

原因：初次接种后，B 细胞增殖分化，除产生浆细胞外还产生了记忆细胞。再次接触同一抗原时，记忆细胞迅速识别抗原，快速增殖分化为大量浆细胞，短时间内产生大量抗体。

这条曲线在坐标图上的表现是：起点更快上升、峰值更高、下降更慢。

五、分层练习

基础

1. 下列细胞中，不能识别抗原的是（　）

A. B 细胞　B. T 细胞　C. 记忆细胞　D. 浆细胞

答案与解析

D

浆细胞的功能是产生和分泌抗体，本身不能识别抗原。B 细胞、T 细胞、记忆细胞都有抗原识别能力。吞噬细胞能识别抗原但没有特异性。

提升

2. 艾滋病患者最终往往死于严重感染或恶性肿瘤，试从免疫学角度解释原因。

答案与解析

HIV 主要攻击 T 细胞，使 T 细胞大量死亡。T 细胞既参与细胞免疫（分化为效应 T 细胞），又能分泌淋巴因子促进 B 细胞增殖分化，因此 T 细胞受损会导致：

① 细胞免疫几乎丧失，无法清除被感染的细胞和癌细胞；

② 体液免疫也受严重影响，抗体产生减少；

③ 免疫监视功能下降，肿瘤发生率升高。

结果是机体几乎丧失全部特异性免疫功能，平时不致病的病原体也会引起严重感染。

选择题稳定 2 道，常考"J 型与 S 型曲线""能量传递效率计算""演替类型判断"。

一、知识主线

1. 种群的数量特征

特征作用
种群密度最基本的数量特征
出生率、死亡率决定种群密度的直接因素
迁入率、迁出率也直接影响种群密度

调查方法：样方法（植物、活动能力弱的动物，随机取样、取平均值）、标志重捕法（活动能力强的动物）。

2. 种群数量增长曲线

类型条件特点公式
J 型食物和空间充裕、无敌害、气候适宜持续增长，增长率不变Nt = N₀λt
S 型资源有限增长速率先增后减，K/2 时增长最快，最终稳定在 K 值—

3. 群落

种间关系：竞争、捕食、寄生、互利共生。判断方法看图：两条曲线同步升降是互利共生，此消彼长且不同步是捕食，一方上升另一方下降是竞争。

群落演替：初生演替（从裸岩、沙丘开始，速度慢）与次生演替（从弃耕农田、火灾后的草原开始，速度快，因为保留了土壤条件和繁殖体）。

4. 生态系统的结构与功能

成分：非生物的物质和能量、生产者、消费者、分解者。生产者是基石，分解者是物质循环不可缺少的环节。

二、高频考点

  • 能量传递效率计算：已知低营养级能量求高营养级最多/最少获得量，按 20% / 10% 两个极端算。
  • S 型曲线的应用：K/2 处增长最快，捕捞后维持在此处可快速恢复。
  • 演替类型判断：看起点有没有土壤和植被。
  • 生态系统稳定性：生物种类越多、营养结构越复杂，抵抗力稳定性越强，恢复力稳定性越弱。

三、易错辨析

易混点辨析
增长速率与增长率J 型曲线增长率不变，增长速率越来越大；S 型曲线增长速率先增后减
能量传递效率 = 摄入量之比？不是。传递效率 = 同化量之比，摄入量中有一部分未被消化吸收（以粪便排出）
分解者一定是微生物？不一定。蚯蚓、秃鹫等动物也是分解者；硝化细菌是生产者
K 值是固定不变的不是。环境条件改变，K 值随之改变
口 诀 能量流动八个字：单向流动、逐级递减，效率 10% 到 20%。
种群增长：J 型无上限，S 型有 K 值；K/2 最快，K 处最稳。

四、例题精解

例　某食物链为：草 → 兔 → 狐 → 狼。若草固定的太阳能为 10000 kJ，求狼最多和最少能获得的能量。

最多：按最高传递效率 20%，每级都按 20% 传递：

10000 × 20% × 20% × 20% = 80 kJ

最少：按最低传递效率 10%：

10000 × 10% × 10% × 10% = 10 kJ

答案：最多 80 kJ，最少 10 kJ。

两个方向别弄反 问"最多获得"→ 用最高效率 20%；问"最少获得"→ 用最低效率 10%。
反过来的题（"狼增重 1 kg 至少消耗草多少"）也要用 20%，因为"至少消耗"意味着效率最高。判断依据是对谁有利就取哪个极端。

基础

1. 下列属于初生演替的是（　）

A. 弃耕农田上发生的演替　B. 火灾后的草原上发生的演替

C. 裸岩上发生的演替　D. 过量砍伐的森林上发生的演替

答案与解析

C

初生演替的起点是从来没有植被覆盖、或原有植被被彻底消灭的地方（裸岩、沙丘、冰川泥）。其余三项都保留了土壤条件甚至繁殖体，属于次生演替。

提升

2. 某湖泊中投放了一种外来鱼类，一段时间后本地小型鱼类数量大幅下降。从生态学角度分析可能的原因及后果。

答案与解析

原因：外来鱼与本地小型鱼生态位重叠，竞争食物和空间；若外来鱼为肉食性，还会直接捕食本地小鱼。由于缺少天敌和寄生生物的制约，其种群可能呈 J 型增长。

后果：本地鱼类种群数量下降甚至局部灭绝，物种多样性降低；食物链结构改变，可能引起浮游生物等更低营养级的连锁变化；生态系统抵抗力稳定性下降。

这类题答题要点是"竞争/捕食 → 数量下降 → 多样性降低 → 稳定性下降"这条链，答到稳定性才算完整。

选考或必考中的一道，通常 10–15 分。流程题为主，背流程比背概念有效。

一、知识主线

1. 发酵工程

环节要点
培养基含碳源、氮源、水、无机盐；按用途分选择培养基和鉴别培养基
灭菌培养基高压蒸汽灭菌；接种环灼烧灭菌；双手酒精消毒（消毒≠灭菌）

计数稀释涂布平板法统计的活菌数往往偏小（两个菌连在一起只长成一个菌落）

2. 细胞工程

技术关键点
植物组织培养原理是细胞的全能性；脱分化形成愈伤组织，再分化形成芽和根；需植物激素（生长素与细胞分裂素比例决定分化方向）
植物体细胞杂交用纤维素酶和果胶酶去壁获得原生质体，用 PEG 诱导融合，克服远缘杂交不亲和的障碍
动物细胞培养需无菌无毒环境、营养、温度 pH、气体环境（95% 空气 + 5% CO₂，CO₂ 维持 pH）
动物细胞融合诱导手段有 PEG、灭活的病毒、电激；用于制备单克隆抗体
核移植体细胞核移入去核卵母细胞，体现细胞核的全能性
单克隆抗体的制备流程 给小鼠注射抗原 → 从脾脏取出 B 淋巴细胞 → 与骨髓瘤细胞融合 → 筛选杂交瘤细胞 → 克隆化培养和抗体检测 → 体内或体外培养 → 提取单克隆抗体。
两个"筛"是关键：第一次筛掉未融合细胞，第二次筛出能产生特定抗体的杂交瘤细胞。

3. 基因工程

工具作用
限制酶识别特定核苷酸序列并在特定位点切割 DNA，产生黏性末端或平末端
DNA 连接酶把两个 DNA 片段连接起来（E·coli DNA 连接酶只连黏性末端，T4 连接酶两种都能连）
载体质粒、噬菌体、动植物病毒；需具备标记基因、限制酶切点、能自我复制
目的基因的获取 → 基因表达载体的构建 → 将目的基因导入受体细胞 → 目的基因的检测与鉴定

检测分三个层次：DNA 分子杂交（是否插入）、分子杂交检测 mRNA（是否转录）、抗原-抗体杂交（是否翻译）。

二、高频考点

  • 灭菌与消毒的区别：灭菌杀死包括芽孢和孢子在内的所有微生物；消毒只杀死部分微生物。
  • 选择培养基的设计：如筛选能分解尿素的细菌，用尿素作唯一氮源；筛选纤维素分解菌，用刚果红染色。
  • 限制酶的选择：不能破坏目的基因和标记基因，要保证目的基因与载体有相同的黏性末端。
  • PCR 技术：变性（90 ℃ 以上解链）、复性（50 ℃ 左右引物结合）、延伸（72 ℃ Taq 酶催化）。

三、易错辨析

易混点辨析
消毒与灭菌酒精擦拭双手是消毒；培养基高压蒸汽处理是灭菌
稀释涂布平板法计数为何偏小两个或多个菌体连在一起时只形成一个菌落，统计值低于实际活菌数
植物组织培养 vs 动物细胞培养前者能发育成完整植株（体现全能性），后者只能获得细胞或细胞产物，不能发育成个体
基因工程是否产生新基因导入的是外源基因，对本物种而言是新基因组合；但基因工程本身属于基因重组层面
口 诀 基因工程四步：取、接、导、检。
细胞工程：植物讲全能，动物讲融合，核移植讲核的全能。

四、例题精解

例　科学家想把人的胰岛素基因导入大肠杆菌，使其大量生产胰岛素。回答：① 获取目的基因后，构建基因表达载体时必须有哪些组成部分？② 如何筛选出成功导入重组质粒的大肠杆菌？

① 基因表达载体必须包含：目的基因、启动子、终止子、标记基因（如抗生素抗性基因），以及复制原点。

启动子是 RNA 聚合酶识别和结合的部位，驱动转录；终止子控制转录终止；标记基因用于后续筛选。

② 筛选方法：用含有相应抗生素的培养基进行选择培养。只有导入了重组质粒（含抗性基因）的大肠杆菌才能在该培养基上生长，未导入的会被淘汰。若要进一步确认，可用 DNA 分子杂交检测目的基因是否插入。

表达载体四个部分缺一不可 少了启动子，目的基因无法转录；少了终止子，转录停不下来；少了标记基因，筛不出来。答题时按"启动子—终止子—标记基因—目的基因"顺序写，不容易漏。

基础

1. 下列关于灭菌和消毒的叙述，正确的是（　）

A. 用酒精擦拭双手属于灭菌

B. 培养基通常用高压蒸汽灭菌

C. 接种环用酒精浸泡消毒

提升

2. 用稀释涂布平板法测定某水样中的细菌总数，取 0.1 mL 稀释 10⁵ 倍的样液涂布，培养后平均长出 40 个菌落。估算原水样中细菌的浓度，并说明该方法可能存在的误差。

答案与解析

约 4.0×10⁷ 个/mL，且实际值可能更高

计算：40 ÷ 0.1 × 10⁵ = 4.0×10⁷ 个/mL。

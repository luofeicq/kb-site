必修第三册 · 第九、十章静电场

高考占比：选择题 1–2 道 + 常与磁场、能量组合成压轴。核心难点是场强与电势是两个独立的量。

一、知识主线

1. 电荷与库仑定律

F = k·q₁q₂/r²　　k = 9.0×10⁹ N·m²/C²

适用条件：真空中的点电荷。方向沿连线，同种相斥、异种相吸。

三个带电体的平衡问题（三个自由电荷都静止）有个固定结论：

三电荷平衡口诀 两同夹异（两边同号，中间异号）、两大夹小（两边的电荷量大，中间小）、近小远大（中间电荷离电量小的那个更近）。

2. 电场强度

E = F/q　（定义式，适用于任何电场）
E = kQ/r²　（点电荷场强，Q 是场源电荷）
E = U/d　（匀强电场，d 是沿场强方向的距离）
公式适用范围谁决定 E
E = F/q任何电场不决定，只是量度方式（q 是试探电荷，不影响 E）
E = kQ/r²点电荷场由场源 Q 和距离 r 决定
E = U/d匀强电场由电势差和板间距决定
最容易混的一对：场强与电势 场强 E 是矢量，描述电场的"力的性质"，看电场线的疏密；
电势 φ 是标量，描述电场的"能的性质"，看电场线的方向（沿电场线电势降低）。
两者没有必然联系：E 大处 φ 不一定高；E = 0 处 φ 不一定为零；φ = 0 处 E 不一定为零。

3. 电场线

特征说明
起止从正电荷（或无穷远）出发，终止于负电荷（或无穷远）
疏密越密表示场强越大
切线某点切线方向就是该点场强方向
不相交任何两条电场线不会相交（否则一点有两个场强方向）
不是轨迹电场线不是电荷的运动轨迹（除非电场线是直线且初速为零或沿电场线）

4. 电势、电势差、电势能

量定义/关系性质
电势 φφ = Ep/q标量，有正负，沿电场线降低
电势差 UABUAB = φA − φBUAB = −UBA
电势能 EpEp = qφ标量，与参考点选择有关
电场力做功WAB = qUAB = −ΔEp与路径无关
电势能正负的判断，只看两件事 ① 电荷的正负；② 电场力做正功还是负功。
电场力做正功 → 电势能减小；做负功 → 电势能增大。这条对正负电荷都成立，不用记那么多口诀。

5. 电容器

C = Q/U　（定义式）　　C = εS/(4πkd)　（平行板电容器决定式）
情况什么量不变板间距 d 增大时
电容器充电后断开电源Q 不变C 减小 → U 增大 → E = U/d 不变
电容器始终接着电源U 不变C 减小 → Q 减小 → E = U/d 减小

这两行是电容器动态分析题的唯一模板：先判断谁不变（Q 还是 U），再依次推 C、U/Q、E。

6. 带电粒子在电场中的运动

情形处理方法关键公式
加速（沿场强方向）动能定理qU = ½mv² − ½mv₀²
偏转（垂直场强射入）类平抛t = L/v₀，y = ½at²，a = qU/(md)

二、高频考点

考法要点
场强叠加矢量和，先算大小再按方向合成
电场线 + 等势面判断电场线密处 E 大；沿电场线 φ 降低；等势面密处 E 大
带电粒子轨迹轨迹向受力方向弯曲；由轨迹可判断电性、做功正负
电容器动态先定 Q 不变还是 U 不变
加速 + 偏转组合加速段用动能定理，偏转段用类平抛
φ–x 图像斜率绝对值是场强大小，斜率正负反映场强方向

三、易错辨析

易错点正确理解
E = F/q 说明 E 与 q 成反比错。E 由场源决定，跟试探电荷无关
场强大的地方电势一定高错。两者独立，如等量异种电荷连线中点 E 最大但 φ = 0
电势为零处场强一定为零错。同上，中点 φ = 0 但 E ≠ 0
电场线就是电荷运动轨迹错。只有电场线是直线、初速为零或沿场线时才重合
W = qU 中 U 的正负搞混UAB = φA − φB，注意先后顺序
电容器断开电源后 E 随 d 变化错。Q 不变时 E = 4πkQ/(εS)，与 d 无关

四、例题精解

例　平行板电容器充电后与电源断开，此时极板带电量为 Q，板间电压为 U，板间场强为 E。若将两极板间距增大为原来的 2 倍，其他条件不变。判断：电容 C、电压 U、场强 E、极板电量 Q 各如何变化。

第一步，判断谁不变。充电后断开电源，电荷无处可去，所以 Q 不变。

第二步，用决定式看 C。

C = εS/(4πkd)，d 变为 2 倍 → C 变为原来的 1/2。

第三步，由定义式推 U。

C = Q/U → U = Q/C。Q 不变、C 变为 1/2 → U 变为原来的 2 倍。

第四步，推 E。

E = U/d = (2U)/(2d) = U/d → E 不变。

也可以直接用 E = 4πkQ/(εS)，与 d 无关，一步看出 E 不变。

结论：Q 不变，C 减半，U 加倍，E 不变。

这题的坎在哪 如果题目改成"始终接着电源"，那 U 不变，结论完全不同：C 减半 → Q 减半 → E = U/d 减半。所以做电容器题，第一句话永远是判断"Q 不变"还是"U 不变"，这一句决定后面全部。

五、分层练习

基础

1. 在真空中，两个点电荷 q₁ = +2×10⁻⁸ C、q₂ = −4×10⁻⁸ C 相距 0.2 m。求它们之间的库仑力大小，并说明是引力还是斥力。（k = 9×10⁹ N·m²/C²）

答案与解析

7.2×10⁻⁴ N，引力

F = k|q₁q₂|/r² = 9×10⁹ × (2×10⁻⁸ × 4×10⁻⁸)/0.04

= 9×10⁹ × 8×10⁻¹⁶/0.04 = 9×10⁹ × 2×10⁻¹⁴ = 1.8×10⁻⁴？

重算：8×10⁻¹⁶/0.04 = 2×10⁻¹⁴，乘 9×10⁹ 得 1.8×10⁻⁴ N。

核实：k q₁q₂/r² = 9×10⁹ × 8×10⁻¹⁶ / 4×10⁻² = 9×10⁹ × 2×10⁻¹⁴ = 1.8×10⁻⁴ N。

答：1.8×10⁻⁴ N，两电荷异号，是引力。

2. 关于电场强度和电势，下列说法正确的是（　）

A. 电场强度大的地方，电势一定高　B. 电势为零的地方，电场强度一定为零

C. 沿着电场线方向，电势逐渐降低　D. 电场强度为零的地方，电势一定为零

答案与解析

C

A、B、D 都错在把 E 和 φ 绑在一起。E 与 φ 相互独立：等量异种电荷连线中点 E 最大而 φ = 0；等量同种电荷连线中点 E = 0 而 φ 不为零（若取无穷远为零电势，中点电势为正）。C 是电场线的基本性质，正确。

提升

3. 电子（质量 m，电量 e）从静止经电压 U₁ 加速后，垂直进入两平行板间的匀强电场，板长 L，板间距 d，偏转电压 U₂。求电子射出偏转场时的侧移量 y 和偏转角正切值 tanθ。（不计重力）

答案与解析

y = U₂L²/(4U₁d)，tanθ = U₂L/(2U₁d)

加速段用动能定理：eU₁ = ½mv₀² → v₀ = √(2eU₁/m)。

偏转段是类平抛。水平方向匀速，飞行时间 t = L/v₀。

竖直方向加速度 a = eE/m = eU₂/(md)。

侧移量 y = ½at² = ½ · eU₂/(md) · L²/v₀² = ½ · eU₂L²/(md) · m/(2eU₁) = U₂L²/(4U₁d)。

竖直分速度 vy = at = eU₂L/(mdv₀)，

tanθ = vy/v₀ = eU₂L/(mdv₀²) = eU₂L/(md · 2eU₁/m) = U₂L/(2U₁d)。

重要结论：结果中不含 e 和 m，说明所有带电粒子的偏转规律相同，与粒子种类无关。这也是为什么示波器对电子和离子都适用。

必修第三册 · 第十一、十二章恒定电流与电路

高考占比：选择题 1 道 + 实验题必考。电路动态分析是稳定考点，实验题分值最大。

一、知识主线

1. 基本概念

I = q/t　　R = U/I（定义式）　　R = ρL/S（决定式）
规律串联并联
电流I = I₁ = I₂I = I₁ + I₂
电压U = U₁ + U₂U = U₁ = U₂
电阻R = R₁ + R₂1/R = 1/R₁ + 1/R₂
功率P ∝ RP ∝ 1/R

2. 闭合电路欧姆定律

E = U外 + U内 = I(R + r)　　→　　I = E/(R + r)

路端电压随外电阻变化的规律：

U = E − Ir = E·R/(R + r)
  • R 增大 → I 减小 → U 增大（趋近 E）
  • R 减小 → I 增大 → U 减小（趋近 0）

3. 电功与电功率

量公式适用范围
电功W = UIt任何电路
电热Q = I²Rt任何电路
纯电阻电路W = Q，P = UI = I²R = U²/R电能全部转化为内能
非纯电阻电路W > Q，P = UI > I²R电动机、电解槽
非纯电阻电路的铁律 电动机工作时：UI = I²r + P机械，其中 r 是电机内阻。
绝不能用 U/R 算电流，也不能用 U²/R 算功率。这两个公式只对纯电阻成立。

4. 电路动态分析——"串反并同"

一个通用的判断方法 某电阻 R 增大时：
与它串联的元件：电流减小、电压减小、功率减小（"反"）；
与它并联的元件：电压增大、电流增大、功率增大（"同"）。
推理的起点永远是"总电阻怎么变 → 总电流怎么变 → 路端电压怎么变"，然后逐个推。

5. 电表改装

改装成连接方式计算
电流表（扩大量程）并联分流电阻R并 = IgRg/(I − Ig)
电压表（扩大量程）串联分压电阻R串 = U/Ig − Rg

二、高频考点

考法要点
电路动态分析从总电阻入手，逐步推总电流、路端电压
电源的功率与效率P总 = EI，P出 = UI，η = U/E = R/(R+r)
电源最大输出功率R = r 时 P出 最大，Pmax = E²/(4r)
U–I 图线纵截距是 E，斜率绝对值是 r
伏安法测电阻大电阻用内接（安培计内接），小电阻用外接
测电源电动势和内阻U = E − Ir，作 U–I 图求 E 和 r

三、易错辨析

易错点正确理解
路端电压随外电阻增大而减小错。R 增大 U 增大，趋近于 E
用 U²/R 算电动机功率错。非纯电阻电路不适用
电源输出功率最大时效率最高错。R = r 时输出功率最大但效率只有 50%
短路时路端电压等于 E错。短路时 U = 0，电流 I = E/r 最大
把 R = U/I 当成电阻的决定式错。这只是量度式，决定式是 R = ρL/S
电表内阻当作理想实际要考虑：电压表分流、电流表分压，这是实验误差的主要来源

四、例题精解

例　电源电动势 E = 12 V，内阻 r = 2 Ω，外电路由 R₁ = 4 Ω 与 R₂ 并联后再与 R₃ = 2 Ω 串联组成。当 R₂ 的阻值由 12 Ω 减小到 4 Ω 时，判断：总电流 I、路端电压 U、R₃ 两端电压 U₃、通过 R₁ 的电流 I₁ 各如何变化。

第一步，看总电阻。R₂ 减小 → R₁ 与 R₂ 的并联电阻减小 → 总电阻 R总 减小。

第二步，推总电流。I = E/(R总+r)，R总 减小 → I 增大。

第三步，推路端电压。U = E − Ir，I 增大 → U 减小。

第四步，推 R₃ 的电压。U₃ = I·R₃，R₃ 不变、I 增大 → U₃ 增大。

第五步，推并联部分电压。U并 = U − U₃。U 减小而 U₃ 增大 → U并 必然减小。

第六步，推 I₁。I₁ = U并/R₁，R₁ 不变、U并 减小 → I₁ 减小。

结论：I 增大，U 减小，U₃ 增大，I₁ 减小。

用"串反并同"快速验证 R₂ 减小（与它并联的 R₁ 应"同"变化，即 I₁ 减小 ✓；与它串联的 R₃ 应"反"变化，即 U₃、I₃ 增大 ✓）。结果与六步推理完全一致。

五、分层练习

基础

1. 电源电动势 6 V，内阻 1 Ω，外接电阻 5 Ω。求电路中的电流、路端电压和电源的效率。

答案与解析

I = 1 A，U = 5 V，η ≈ 83.3%

I = E/(R+r) = 6/(5+1) = 1 A。

U = IR = 1×5 = 5 V（或 U = E − Ir = 6 − 1 = 5 V）。

η = U/E = 5/6 ≈ 83.3%。

2. 一台电动机接在 220 V 电源上，通过的电流为 5 A，电机内阻为 2 Ω。求：(1) 电动机的输入功率；(2) 发热功率；(3) 输出的机械功率。

答案与解析

(1) 1100 W　(2) 50 W　(3) 1050 W

(1) P入 = UI = 220×5 = 1100 W。

(2) P热 = I²r = 25×2 = 50 W。

(3) P机 = P入 − P热 = 1100 − 50 = 1050 W。

注意：不能用 P = U²/r = 220²/2 算，那是纯电阻电路的算法，电动机不是纯电阻。

提升

3. 电源电动势 E = 6 V，内阻 r = 1 Ω，外接可变电阻 R。求：(1) R 为多大时电源输出功率最大，最大值是多少；(2) 此时电源的效率。

答案与解析

(1) R = 1 Ω，Pmax = 9 W　(2) 50%

(1) 输出功率 P = I²R = [E/(R+r)]²·R = E²R/(R+r)²。

用数学方法：P = E²R/[(R−r)² + 4Rr] = E²/[(R−r)²/R + 4r]。

当 R = r 时分母最小，P 最大：Pmax = E²/(4r) = 36/4 = 9 W。

(2) 此时 η = R/(R+r) = 1/2 = 50%。

结论要点：输出功率最大时效率只有 50%。实际输电追求高效率，会让 R ≫ r，此时输出功率反而小。这是"功率最大"和"效率最高"的矛盾，考试常拿来设陷阱。

必修第三册 · 第十三章 / 选择性必修第二册 · 第二、三章电磁感应与交变电流

高考占比：极高，几乎每年必有一道电磁感应大题（导体棒切割 + 能量/动量）。这是物理最难的板块之一。

一、知识主线

1. 磁通量与楞次定律

Φ = B·S·cosθ　（θ 是 B 与面积法线的夹角）
楞次定律：四字诀"增反减同" 磁通量增加时，感应电流的磁场与原磁场反向；
磁通量减小时，感应电流的磁场与原磁场同向。
本质是"阻碍变化"，不是"阻止变化"——它只是让变化变慢，不会让变化不发生。

推广形式：来拒去留（磁体靠近时排斥，远离时吸引）、增缩减扩（线圈面积有缩小或扩大的趋势）。

2. 法拉第电磁感应定律

E = n·ΔΦ/Δt　（n 是线圈匝数）
E = BLv　（导体棒垂直切割磁感线，L 为有效长度，v 为垂直 B 的速度分量）
公式求的是适用
E = nΔΦ/Δt平均电动势任何情况
E = BLv瞬时电动势导体棒切割磁感线
E = ½BL²ω瞬时电动势导体棒绕一端转动

3. 导体棒切割磁感线的标准模型

这是电磁感应大题的核心模型，几乎所有的题目都是它的变体。

环节方程说明
感应电动势E = BLvv 变化时 E 也变
感应电流I = E/(R+r) = BLv/(R+r)r 是棒的内阻
安培力F安 = BIL = B²L²v/(R+r)方向总与运动方向相反
牛顿第二定律F − F安 = mav 增大则 a 减小，最终匀速
最大速度vmax = F(R+r)/(B²L²)a = 0 时
三个"能量关系"，务必分清 安培力做负功：机械能减少，转化为电能；
安培力做正功：电能减少，转化为机械能（电动机）；
焦耳热：Q = I²Rt，等于电路中消耗的电能。整个过程中：外力做的功 = 增加的动能 + 焦耳热。

4. 电磁感应中的动量问题

导体棒在磁场中受安培力，安培力的冲量可以求和：

∫F安dt = ∫BIL dt = BL∫I dt = BLq

而 q = ΔΦ/(R+r) = BLΔx/(R+r)，所以：

BLq = BL·BLΔx/(R+r) = B²L²Δx/(R+r)

这就是"安培力冲量 = B²L²Δx/(R+r)"，配合动量定理可解"求位移"类问题，是压轴题的常用套路。

5. 交变电流

量表达式备注
瞬时值e = Em·sinωt（从线圈平面平行于 B 开始计时）中性面时 e = 0
峰值Em = nBSω与转速成正比
有效值E = Em/√2（正弦式）电表读数、电功率计算都用有效值

变压器：

U₁/U₂ = n₁/n₂　　I₁/I₂ = n₂/n₁（单一副线圈）　　P₁ = P₂

远距离输电：P损 = I²R线，所以提高输电电压可以减小电流，从而大幅降低线损。

二、高频考点

考法要点
楞次定律判断方向先定原磁场方向，再看 Φ 增减，最后定感应电流磁场方向
导体棒切割v 变 → E 变 → I 变 → F安 变 → a 变，最终匀速
电磁感应 + 能量用能量守恒求焦耳热，比积分省事
电磁感应 + 动量用 BLq = B²L²Δx/(R+r) 求位移
图像问题Φ–t 图斜率是 E；i–t 图要注意方向
变压器电压比 = 匝数比；功率相等；频率不变

三、易错辨析

易错点正确理解
楞次定律理解为"阻止变化"错。是"阻碍"，只让变化变慢，不能阻止
E = BLv 中的 L 用导体总长错。用有效长度（垂直于 v 和 B 的投影长度）
磁通量为零时感应电动势为零错。Φ = 0 时 ΔΦ/Δt 可以最大（线圈平面平行 B 时）
安培力总是做负功错。电动机中安培力做正功
变压器能改变频率错。变压器只变电压电流，频率不变
电表读数是峰值错。交流电表读的是有效值
导线框完全进入磁场后仍有感应电流错。完全进入后 Φ 不变，无感应电流（但仍有感应电动势吗？也没有，因为 ΔΦ = 0）

四、例题精解

例　水平放置的两条光滑平行金属导轨间距 L = 0.5 m，处于竖直向下的匀强磁场中，磁感应强度 B = 0.4 T。导轨上放一根质量 m = 0.2 kg、电阻 r = 0.5 Ω 的金属棒，导轨另一端接有 R = 1.5 Ω 的电阻，导轨电阻不计。用水平恒力 F = 0.4 N 拉棒由静止开始运动，棒与导轨间摩擦不计。求：(1) 棒的最大速度；(2) 棒达到最大速度时，外力做功的功率；(3) 从静止到最大速度过程中，若棒移动了 2 m，求这一过程中产生的焦耳热。

第一步，受力与运动分析。棒受向右的拉力 F 和向左的安培力 F安。速度增大 → 感应电动势增大 → 电流增大 → 安培力增大 → 合力减小 → 加速度减小。当 F安 = F 时速度最大，此后匀速。

第二步，求最大速度。

F安 = BIL = B·(BLv/(R+r))·L = B²L²v/(R+r)。

令 F安 = F：

B²L²vmax/(R+r) = F

0.4²×0.5²×vmax/(1.5+0.5) = 0.4

0.16×0.25×vmax/2 = 0.4

0.04vmax/2 = 0.4 → 0.02vmax = 0.4 → vmax = 20 m/s。

第三步，求外力的功率。匀速时外力功率 = 安培力功率（全部转为电功率）：

P = F·vmax = 0.4×20 = 8 W。

第四步，用能量守恒求焦耳热。从静止到 2 m 处，动能从 0 增到 ½mv²，外力做功 F·x，其余变成热量：

F·x = ½mvmax² + Q

0.4×2 = ½×0.2×400 + Q

0.8 = 40 + Q → Q = −39.2 J？

发现问题：位移 2 m 时棒还没到 20 m/s。需要用动量定理求实际速度。

由动量定理：Ft − ∫F安dt = mv，其中 ∫F安dt = B²L²x/(R+r)。

0.4t − 0.04×2/2 = 0.2v …这需要 t，题目未给，说明题目应理解为"已充分加速"。实际考试中此类问法通常给"移动 2 m"时已接近最大速度，此时可近似 v ≈ vmax 计算，或题目本意就是求"达到稳定速度后移动 2 m"的过程。

修正理解：若题意为"棒已达到最大速度后继续移动 2 m"，则速度不变、动能不变，外力做功全部转为热量：

Q = F·x = 0.4×2 = 0.8 J。

这题暴露的两个问题 ① 这类题必须注意"是否已达稳定速度"，否则动能项会算出负值这种荒谬结果，说明前提不成立；
② 若真要算"从静止到 2 m"的焦耳热，必须先用动量定理求出该时刻的速度：
　Ft − B²L²x/(R+r) = mv，还需要 t，而 t 可由 ∫dt 解出（涉及指数衰减），超出高中要求。所以高中题一定会在题目里说清"已达最大速度后"或直接给时间。

五、分层练习

基础

1. 闭合线圈放在匀强磁场中，下列哪种情况会产生感应电流（　）

A. 线圈在磁场中匀速平动，且始终完全在磁场内

B. 线圈绕垂直于磁场的轴匀速转动

C. 线圈静止在增强的磁场中

D. 线圈在磁场中沿磁感线方向平动

答案与解析

B、C

产生感应电流的条件是穿过线圈的磁通量发生变化。

A：完全在匀强磁场内平动，Φ = BS 不变，无感应电流。

B：转动时线圈平面与 B 的夹角变化，Φ 变化，有感应电流（这就是交流发电机）。

C：磁场增强，Φ 增大，有感应电流。

D：沿磁感线平动，若线圈平面与 B 垂直，Φ 不变；若平行，Φ 始终为零，也不变。总之无感应电流。

2. 理想变压器原、副线圈匝数比 n₁ : n₂ = 10 : 1，原线圈接 220 V 交流电，副线圈接一个 22 Ω 的电阻。求副线圈的电压、电流和原线圈的电流。

答案与解析

U₂ = 22 V，I₂ = 1 A，I₁ = 0.1 A

U₁/U₂ = n₁/n₂ → 220/U₂ = 10 → U₂ = 22 V。

I₂ = U₂/R = 22/22 = 1 A。

I₁/I₂ = n₂/n₁ = 1/10 → I₁ = 0.1 A。

验算功率：P₁ = 220×0.1 = 22 W，P₂ = 22×1 = 22 W，相等 ✓。

提升

3. 光滑水平导轨间距 L = 1 m，处于竖直向下的匀强磁场中，B = 0.5 T。导轨上两根金属棒 a、b 质量均为 m = 0.1 kg，电阻均为 R = 0.5 Ω，导轨电阻不计。开始时 b 静止，a 以 v₀ = 4 m/s 向右运动。求：(1) 最终两棒的共同速度；(2) 全过程产生的焦耳热；(3) 通过棒的总电荷量及 a 移动的距离。

答案与解析

(1) 2 m/s　(2) 0.4 J　(3) q = 0.8 C，Δx相对 = 0.8 m

(1) 两棒系统所受外力为零（安培力是内力），动量守恒：

mv₀ = 2mv → 0.1×4 = 0.2v → v = 2 m/s。

(2) 初动能 Ek1 = ½×0.1×16 = 0.8 J，末动能 Ek2 = ½×0.2×4 = 0.4 J。

Q = 0.8 − 0.4 = 0.4 J。

(3) 对 b 棒用动量定理：安培力冲量 = 动量变化。

BIL·t = BLq = mv − 0 = 0.1×2 = 0.2

q = 0.2/(BL) = 0.2/(0.5×1) = 0.4 C（单棒）。

注意：这里是流过单棒的电荷量。若问"通过回路的总电荷量"，也是 0.4 C。

由 q = ΔΦ/(2R) = BLΔx相对/(2R)：

0.4 = 0.5×1×Δx/(1.0) → Δx相对 = 0.8 m。

（a、b 各自位移需再结合动量守恒分配：a 走 0.4 m，b 走 0.4 m，相对位移 0.8 m。）
